# 宁大助手 Lite

[![Build](https://github.com/LinkUNIv/nbu-assistant-lite/actions/workflows/build.yml/badge.svg)](https://github.com/LinkUNIv/nbu-assistant-lite/actions/workflows/build.yml)

把课表、资讯、校历和常用校园入口收进一个 Android 应用。**课表离线可用，不需要登录任何校内系统。**

> **非官方第三方工具。** 与宁波大学无隶属、合作或授权关系；名称中的「宁大」仅用于说明适用学校。
> 使用前请阅读[免责声明](#免责声明)。

---

## 特性

| 模块 | 能力 |
|---|---|
| **课表** | 导入教务导出的 Word / Excel（`.xlsx` / `.xls` / `.docx` / `.doc`-RTF，自研解析，无第三方库）；也可手动录入。周视图自适应屏宽，左侧节次栏固定显示节次与起止时间 |
| **停课 / 调课** | 点某一节可设为「停课」或「调整时间」，仅本周或本周起每周生效，随时可恢复原安排 |
| **上课提醒** | 开课前 30 分钟与 15 分钟各提醒一次；上课期间可在通知栏挂一条剩余时间倒计时 |
| **资讯** | 新闻网 4 个栏目与「教务处通告」混合成一条时间线，按发布时间倒序；含正文与配图，保留原文链接 |
| **校历** | 内置两学年结构化作息与事件；另可查看官方校历原图 |
| **入口** | 教务、选课、图书馆、校园卡、邮箱、WebVPN 等，**一律交给系统浏览器** |

**不登录、不采集。** 不接入统计与广告 SDK，不保存任何账号或会话凭证；「校园入口」只做跳转，页面内容不经过本应用。

## 下载

到 [Releases](../../releases) 下载 `-Preview` 的 APK 直接安装，无需 root、无需电脑。

- 当前处于 **0.x 预览阶段**，功能与数据格式都可能变动，不建议当成唯一课表来源
- 覆盖安装不会丢数据；只有卸载重装才会清空
- 测试通道与正式版包名不同，可以同时安装

---

## 构建

需要 JDK 17、Android SDK Platform 36 与 Build-Tools 36.0.0。Gradle 版本由 wrapper 固定。

```bash
./gradlew :app:assemblePreview   # 预览包（日常测试）
./gradlew :app:assembleDebug     # 调试包（排查问题）
```

推送提交后，GitHub Actions 会自动编译并上传 APK 产物；打 `v*` 标签则自动生成 Release。

技术栈：Kotlin + Jetpack Compose + Room + OkHttp + Jsoup + Coil，手动依赖注入。

开发与发版相关的约定见 [`docs/DEVELOPING.md`](docs/DEVELOPING.md)。

## 数据来源与版权

| 来源 | 用途 | 方式 |
|---|---|---|
| `news.nbu.edu.cn` | 要闻 / 动态 / 媒体 / 人物 | 公开栏目页，列表 + 正文 + 配图 |
| `jwc.nbu.edu.cn` | 教务处通知公告 | 同上 |

- 校历依据教务处公开校历人工整理，未与原文核对的学年会在页脚提示。
- **分发或再发布本应用前，请自行复核上述内容的转载授权。**

## 已知限制

- **不做应用内登录。** 信息门户的 SPA 在系统 WebView 内无法稳定渲染，该方案已整条移除 ——
  这也是本应用「只跳转、不碰凭证」的由来。
- 2026–2027 学年校历尚未与教务处原文逐条核对。
- 资讯正文属转载，分发前需自行评估授权。
- 暂无桌面小组件；仅在 Android 上验证（minSdk 24）。
