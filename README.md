# 宁大助手 Lite

> **非官方第三方工具，与宁波大学无隶属、合作或授权关系。** 名称中的「宁大」仅用于说明适用学校，
> 不代表任何官方身份。使用前请阅读文末[免责声明](#免责声明)。

把课表、资讯、校历、常用校园入口收进一个 Android 应用，**课表离线可用**。

- 不登录任何校内系统，不保存任何凭证
- 不采集个人信息，不接入统计与广告 SDK
- 所有「校园入口」只做跳转，页面内容不经过本应用

---

## 功能

| 模块 | 能力 |
|---|---|
| **课表** | 导入教务导出的 Word / Excel（`.xlsx` / `.xls` / `.docx` / `.doc`-RTF，自研解析，无第三方库）；也可手动录入。周视图自适应屏宽，左侧节次栏固定显示节次与起止时间 |
| **停课 / 调课** | 点某节课可设为「停课」（默认仅本周）或「调整时间」（仅本周 / 本周起每周），按周生效，可随时恢复原安排 |
| **资讯** | 新闻网 4 个栏目 + 「教务处通告」混合成一条时间线，按发布时间倒序；含正文与配图，保留原文链接；支持下拉刷新 |
| **校历** | 内置两学年结构化作息与事件；另有「官方校历原图」可抓取 `nbu.edu.cn/xl.htm` 的官方图片，支持应用内全屏查看与跳浏览器 |
| **入口** | 教务、选课、图书馆、校园卡、邮箱、WebVPN 等，**一律交给系统浏览器**，应用不注入脚本、不读页面、不保存 Cookie |
| **离线** | 无网络时仅课表可用，其余模块明确显示网络状态（无网络 / 源不可达 / 正常） |

**一键去导出**：「导入课表」弹窗内提供「打开信息门户」按钮 —— 教务系统须经统一身份认证门户
（`i.nbu.edu.cn`）进入，直连子系统地址在校外或非内网时通常打不开。

## 数据来源与版权

| 来源 | 用途 | 抓取方式 |
|---|---|---|
| `news.nbu.edu.cn` | 要闻 / 动态 / 媒体 / 人物 | 公开栏目页，列表 + 正文 + 配图 |
| `jwc.nbu.edu.cn/tzgg1.htm` | 教务处通知公告 | 同上 |
| `www.nbu.edu.cn/xl.htm` | 官方校历原图 | 只解析「学年 → 图片地址」，结构化日期走本地 JSON |
| 教务导出文件 | 课表 | 由用户从教务系统导出后**手动导入**，不自动获取 |

- 以上均为**公开页面**，抓取不涉及登录态、不绕过任何访问控制。
- 文章与图片**版权归宁波大学及原作者所有**。本应用仅作阅读索引：正文缓存只存在于**本机数据库**，
  不上传、不聚合、不二次分发；每条内容均保留原文链接与来源标注。
- 校历数据依据教务处公开校历人工整理，`verified` 字段标记是否已与原文核对，未核对的学年会在页脚提示。
- **分发或再发布本应用前，请自行复核上述内容的转载授权。**

## 构建

| 项 | 版本 |
|---|---|
| JDK | 17 |
| Android SDK | Platform 34、Build-Tools 34.x |
| Gradle | 8.7（`gradle/wrapper` 已固定） |
| minSdk / targetSdk | 24 / 34 |

```bash
./gradlew :app:assembleDebug     # 调试包（applicationId 带 .debug 后缀）
./gradlew :app:assembleRelease   # 发布包（当前未配置签名，产出 unsigned）
tools/archive-release.sh         # 归档到 dist/archive/v<版本>/（-f 覆盖同版本）
```

**路径要求**：`gradle.properties` 里有 `android.overridePathCheck=true`，用于在含非 ASCII 字符的路径下
构建（AGP 默认会拒绝）。更稳妥的做法仍是将项目放在纯 ASCII 路径下。

**当前不包含发布签名配置**：`release` 构建类型没有 `signingConfig`，因此不会产出可分发 APK。
正式分发需要自行生成 keystore —— 一旦对外发布，**该 keystore 必须长期保持不变**，
否则已安装用户无法覆盖升级（Android 以签名区分应用身份）。

## 版本规则

版本号 `主.次.修订`：

- **主位**：架构级或不兼容变更
- **次位**：新增功能模块
- **修订位**：修 bug、文案、样式、微调

`versionCode = 主 × 10000 + 次 × 100 + 修订`，每版递增以保证可覆盖安装。
每次出包由 `tools/archive-release.sh` 归档到 `dist/archive/v<版本>/`（APK + 源码快照 + SHA-256）。
**`dist/` 不入库**，构建产物通过 Release 分发。变更记录见 [`CHANGELOG.md`](CHANGELOG.md)。

## 代码结构

```
app/src/main/java/app/nbult/lite/
├─ data/db/        Room 实体、DAO、数据库迁移
├─ data/remote/    资讯与校历抓取、服务器校时
├─ data/repo/      课表 / 资讯仓库
├─ domain/         时间与周次计算、周次位图、停课调课合成
├─ parser/         xlsx / docx / rtf / HTML 表格 / 文本网格解析
├─ net/            网络状态监控（三态）
├─ ui/timetable/   固定节次栏 + 分页网格、导入、课程与停课调课编辑
├─ ui/news/        资讯列表与详情
├─ ui/calendar/    校历、官方原图查看器
├─ ui/portal/      校园入口（纯跳转）
├─ ui/settings/    设置、日志导出
└─ util/           日志、崩溃捕获、外部链接、帧统计
app/src/main/assets/
├─ calendar/       校历数据（人工结构化的 JSON）
└─ portal/         入口配置（改入口不必改代码）
```

技术栈：Kotlin + Jetpack Compose + Room + OkHttp + Jsoup + Coil，手动依赖注入（不使用 Hilt）。

## 已知限制

- **不做应用内登录**：曾尝试用 WebView 打开信息门户，但其 SPA 在系统 WebView 内无法稳定渲染
  （12 个脚本一个都未执行），该实验功能已于 0.14.0 整条移除。这也是本应用"只跳转、不碰凭证"的由来。
- **校历 2026–2027 学年尚未与教务处原文逐条核对**。
- **资讯正文属转载**，分发前需自行评估授权。
- 尚无桌面小组件、上课提醒。
- 仅在 Android 上验证（minSdk 24，开发机为 Android 14+ / 高刷屏）。
