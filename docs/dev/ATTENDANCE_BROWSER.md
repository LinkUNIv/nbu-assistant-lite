# 点名、账号、相机与诊断

## 页面与加载策略

入口直接访问 `https://attendance.nbu.edu.cn/h5/student/schedule/`，未登录时跟随学校统一认证。原生认证覆盖层仅信任 `https://uis.nbu.edu.cn/authserver/`，一级登录、二次验证码与设备信任页面等待实际加载完成和文档 complete 后检测，间隔 1 秒；回到前台不等同于加载完成。课程列表从导航开始按 250ms 检测，读取学校已渲染课程并由原卡片执行跳转。网页结构改变时可选择原网页继续。

UA 由 `browser/BrowserIdentity.kt` 统一提供：固定前缀（机型、系统、Chrome 版本）写在代码里，`cpdaily/{v} wisedu/{v}` 的版本号段可单独调整，浏览器与预加载共用同一来源。实际 WebView 内核以系统为准，UA 不提供原生 JSBridge。TLS 错误拒绝访问，允许学校 HTTPS 认证跳转与跨域 Cookie。会话由 WebView 保存在应用私有目录；更改或清除账号会清理 Cookie 和网页存储。

## 账号与预加载

“我的 → 账号”通过 Android Keystore 的 AES-GCM 加密保存可选凭据，只显示账号及密码保存状态。每次浏览器自动尝试一次密码登录，勾选学校七天免登录；验证码、设备信任及额外验证由用户处理。

长按点名可设置课程列表 UI、唯一开放课程自动进入和预加载，默认开启；预加载依赖自动跳转。预加载只在应用前台、本地课程开始前 15 分钟至末节结束前运行，不是后台常驻服务。匹配开放课程后可将同一个 WebView 转交前台，不自动提交签到。课程是否开放按学校数据判断（存在 coursePlanId 且 attendanceState 为 0），名称忽略空白后匹配。

## 相机 OCR

用户主动进入取景框；相机权限可拒绝，仍可使用应用内数字键盘。图片只在内存处理。CameraX 后摄支持缩放、点击对焦与测光；内置 ML Kit 中文模型无需另行下载。颜色定位、候选裁图、原色/色差增强与全图回退用于识别四位纯数字，单帧有效候选即可提交。重复码去重，未返回结果不并发提交，学校成功后停止。长按主界面点名按钮，在点名设置页进入相机 OCR 测试。该入口共用识别链路，仅显示结果，直到用户退出。

泛白投影样本在同机离线对比中仍没有完整四位候选；颜色定位/预处理测试通过不能代替完整 OCR 验收。私有样本从源码外部通过 `-PocrFixtureDir=/path/to/private-fixtures` 注入 AndroidTest；没有样本时跳过对应测试。该样本回归目前仍可能失败，须如实保留结果。

## 日志范围

- 所有通道：本机时间、会话 ID、事件顺序、去查询参数的 URL 路径、请求方法、HTTP/网络/TLS 错误、fetch/XHR 状态耗时、点击元素标签及页面路由。普通控制台错误只记来源行号，隐藏消息。
- 仅 Debug：学校考勤 API 请求参数及 JSON 响应，可能包含签到码与课程数据；学生页面点击、按下/抬起顺序、DOM 结构与变化、元素文字、坐标及输入值。密码、隐藏输入和匹配令牌字段隐藏；不记录请求头、Cookie 或认证响应正文。脱敏不能视为匿名化承诺。
- 基础日志两份各约 5MB，Debug 两份各约 50MB 滚动。超长接口事件约 64K 截断并标记，DOM 事件分片。旧记录会淘汰，不是无限抓包。
- Service Worker、原生桥和未被观察到的页面内部行为可能遗漏。HTTP 200 不等于业务成功，须查看业务结果或学校提示。
- 导出前检查内容，不把原始日志、课表或照片提交到公开仓库。预览版不启用 Debug 详细观察脚本。

## 验证

`node tools/test-browser-observer.cjs` 检查基础观察器不改变请求与响应、去除查询参数且不记录模拟凭据；`./gradlew :app:testPreviewUnitTest` 运行本地逻辑测试。完整登录、网页结构兼容、桌面点击与相机取景仍需真机验收。

## 签到码输入同步

应用内数字键盘只点击学校 `.key-board` 下的按键，读取 `.code-view` 作为数字显示来源。按键串行执行，等待网页实际显示预期数字后才执行下一次输入；四位全部确认后自动点击学校确认键。OCR 与手动输入共用这一链路。失败响应、HTTP/网络错误或 15 秒未收到结果时，重置网页与遮罩；超时不代表服务器一定未签到，须关注学校返回状态。不会调用手机输入法。

`node tools/test-sign-input.cjs` 检查重复数字、延迟 DOM 更新、网页自动清空、重置与站点限制。
