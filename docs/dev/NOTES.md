# 宁大助手 Lite

非官方第三方效率工具（路线 B「效率外壳」）。不登录、不采集个人信息、不调用学校私有接口。

- **课表**：网页读取 / Word、Excel 导入 / 手动输入 → 本地解析 → 周视图（自适应屏宽）、今日剩余、点击编辑、离线可用
- **资讯**：抓取新闻网公开内容，含正文与配图（严格限定正文容器），保留原文链接与来源
- **时间**：东八区计算、服务器校时、官方作息模板、开学时间自动识别
- **无网络**：仅课表可用，其余模块显示网络状态

## 一、环境要求

| 项 | 版本 |
|---|---|
| JDK | 17（AGP 8.5 要求） |
| Android Studio | Koala (2024.1) 或更新 |
| Android SDK | Platform 34、Build-Tools 34.x |
| Gradle | 8.7（`gradle-wrapper.properties` 已指定） |

## 二、构建与发布

```bash
./gradlew :app:assembleDebug
tools/archive-release.sh        # 归档（-f 覆盖同版本）
```

> ⚠️ 项目路径不能含中文，AGP 会拒绝。已用 `android.overridePathCheck=true` 绕过，更稳是放纯 ASCII 路径。

## 三、课表导入（两种方式）

| 方式 | 路径 | 说明 |
|---|---|---|
| ① 文件导入 | 导入 → 选择文件 | `.xlsx` / `.xlsm` / `.docx` / `.doc`（RTF）；自研解析，无第三方库 |
| ② 手动输入 | 导入 → 手动输入课程 | 填名称/教师/地点/星期/节次/周次，直接入库 |

**已下线**：应用内登录教务系统读取课表（含 WebView、UA 切换、清网页缓存）。
原因是学校门户的 SPA 在 WebView 中无法稳定渲染，且该通道需要用户在第三方容器内输入密码，
收益与风险不成比例；教务导出的文件解析已验证可用，是更稳的路径。

**已移除**：纯文本粘贴、`.txt` / `.csv` / `.html` 文件导入。

**支持的导出格式**（已用教务真实导出件校准，样本存于 `docs/samples/reference/`）：

```
【理论】101G02A-模拟电子技术[01]      ← 课程名（保留课号，格子里只显示名称部分）
陈飞飞2                                ← 教师（自动去尾部编号）
1-15周,星期1,3-4节,北区1号教学楼205     ← 周次,星期,节次,地点
```

`.doc` 为 RTF 编码时直接解析（处理 `\uNNNN` 中文、`\binN` 内嵌图片）；若为旧版二进制 `.doc`，会提示另存为 `.docx`。

## 四、课表界面

| 特性 | 说明 |
|---|---|
| 屏宽自适应 | 7 列按可用宽度均分，**不再左右滑动**；窄屏自动降字号与信息密度 |
| 时间显示 | 左侧节次列同时显示节次号与开始时间（取当前作息表） |
| 教师显示 | 课程块内显示教师；节次 ≥2 时同时显示教师与地点 |
| 今日卡片 | 只显示**尚未结束**的课程；当天全部结束后自动切到**次日课程** |
| 点击编辑 | 改课程名/教师/地点/星期/节次/周次，可删时段或整门课 |
| 空态 | 仅当课表 0 条记录才显示「还没有课表」，单周无课只显示提示条 |

## 五、时间与时区

| 机制 | 说明 |
|---|---|
| 时区固定 | 全部日期计算按 `Asia/Shanghai`，设备时区异常不影响「第几周」 |
| 服务器校时 | 读 `news.nbu.edu.cn` 响应头 `Date`，显示偏差、可一键恢复设备时间 |
| 作息模板 | 主校区 / 梅山校区两套，依据公开校历 |
| **开学时间自动识别** | 我的 → 学期设置 → 自动识别：抓取新闻网「开学/开课/校历」类文章，从正文或发布日期推断第一周周一 |
| 手动优先 | 手动改过日期后标记 manual，自动识别结果不再覆盖（再次点「自动识别」可重新覆盖） |

自动识别的现实约束：新闻网分页非时序（`/ndyw/2.htm` 会返回 2005 年内容），因此只在栏目首页可见的文章里找线索；学期开始距今较远时可能识别不到，此时降级为手动设置——这也是保留手动入口的原因。

## 六、资讯抓取

| 项 | 说明 |
|---|---|
| 来源 | 4 个栏目（要闻/动态/媒体/人物） |
| 正文容器 | 按站点模板依次尝试 `#vsb_content` → `div.v_news_content` → `.conlis .cen` → `.conlis` → `article` |
| 图片过滤 | 排除 `cenr/side/right/recommend/footer` 等噪声容器；排除宽≤160 或高≤80 的小图；非 `/__local/` 且含 `/images/` 的模板图一律丢弃 |
| 实测 | 老模板页（校庆公告）取到 1 张正文图；新闻页取到 8 段正文 + 1 张正文图；侧栏 4 张横幅不再误抓 |
| 时机 | 进详情页才抓正文并落库，二次进入秒开 |

## 七、版本与留档

版本号 `主.次.修订`：主=架构级/不兼容；次=新增功能模块；**修订=小改动（修 bug、文案、样式）**。

`versionCode = 主*10000 + 次*100 + 修订`，每版必须递增。

每次出包归档到 `dist/archive/v<版本>/`：APK + 源码快照 zip + `RELEASE.md`（含 SHA-256）。变更记录见 `CHANGELOG.md`。

## 九、存储与重置

「我的 → 存储与重置」：

| 操作 | 范围 | 影响 |
|---|---|---|
| 恢复出厂设置 | 课表 + 资讯 + 全部设置 + 日志 | 回到首次安装状态，二次确认并列明删除项 |

工作日志自动瘦身（保证体积始终很小）：

- 单条最长 500 字符，超出截断
- 内存保留 **3 天**、最多 **500 条**，超期/超量自动丢弃
- 导出文件保留 **3 天**、最多 **5 个**，启动与每次导出时清理

## 十一、滑动性能

课表左右滑动是唯一的高频动画路径，针对它做了四件事：

| 措施 | 说明 |
|---|---|
| 无嵌套滚动 | 课表铺满一屏，行高按可用高度反算（30–64dp），彻底去掉 `verticalScroll` 包裹分页 |
| 相邻页降级（仅静止时） | 静止时非当前页只画色块与课名；**滑动中所有可见页都完整渲染**，避免“过半瞬间内容凭空出现/消失”的撕裂 |
| 绘制取代布局 | 网格线用 `drawBehind` 一次画完；课程块由单个 `Layout` 统一 `place`（不再每块一个 RenderNode）；块边框自绘 |
| 文案预计算 | 时间区间、周次标签在数据变化时算好，绘制阶段只读字段 |

**动效规格**：全应用统一 `MotionSpecs.Decelerate = cubic-bezier(0.05, 0.7, 0.1, 1)`（起步即最大速度、末速归零）。
Pager 吸附用 `tween(280)` 替代默认 `spring()`（弹簧从 0 速起步，观感像“先加速”）；箭头切周同曲线；
Tab 转场位移与淡入淡出等时长。「精致动效」可叠加高斯模糊，代价是多一层离屏渲染。

**尺寸外置**：列宽/行高在分页外算一次传入，每页不再各带一个 `BoxWithConstraints`（SubcomposeLayout）。
课程块点击改为单个 `pointerInput` 命中测试，去掉每块一个 `clickable`。

**帧率声明**：`MainActivity` 通过 `preferredDisplayModeId` 请求屏幕最高刷新率，
避免 LTPO 把非游戏应用压到 60Hz。滑动期间用 `Choreographer` 统计帧耗时并写入工作日志。

**文字节点合并**：每个课程块原来用 5 个 `Text`（课名/教师/地点/开始/结束），现合并为 2 个
（课名+教师、地点+起止+周次）；表头与节次列也各自合并。单页文字节点约 140 → 60，
滑动时两页同绘，这是掉帧最直接的改善项。

## 十二、校历

底部第三个 Tab，数据来自内置 `assets/calendar/nbu_calendar.json`。

| 内容 | 说明 |
|---|---|
| 学年切换 | 2025~2026（已核对）、2026~2027（待核对） |
| 当前状态 | 学期 / 第几周 / 今日事项 / 接下来两条 |
| 事件列表 | 按月份分组，今天高亮；类型分假期、报到、上课、运动会、补课 |
| 上课时间表 | 主校区 / 梅山校区，含上下班时间与自习节说明 |

为什么不直接爬：校历以**通知或图片**形式发布，没有可机读接口。因此做成「人工结构化 + 随版本发布」，
每年两次维护即可；`verified` 字段用于标记是否已与教务处原文核对，未核对的学年会在页脚红字提示。
