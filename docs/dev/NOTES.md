# 设计取舍与踩坑（历史）

> **本文只记"为什么这么做、后来又为什么改掉"**，不写操作步骤。
> 想看怎么构建/发版 → `DEVELOPING.md`；想看架构与分工 → `ARCHITECTURE.md`；
> 想看还要做什么 → `PENDING.md`；想按版本看做过什么 → `CHANGELOG.md`。
>
> 2026-11-20 重整：删掉了与上述文档重复的章节（环境要求、构建发布、代码结构、
> 版本留档、构建产物），只保留仍然有参考价值的取舍与教训。

## 一、为什么下线"应用内登录教务读取课表"

早期做过 `ui/webimport`：内嵌 WebView 打开学校门户，用户在里面登录，再把课表读出来。

放弃的原因有三条，缺一不可：

1. 门户是 SPA，WebView 里渲染不稳定，注入脚本随学校前端改版反复失效。
2. 需要用户在**第三方容器**里输入学校密码——收益与风险完全不成比例。
3. 教务导出的文件解析已被真实导出件验证可用，是更稳的路径。

结论：**只支持文件导入与手动录入**，不碰学校账号。这条至今没变，也是本项目
"不登录、不采集"定位的来源。

## 二、课表导入：为什么只保留两种入口

- **文件**（`.xlsx` / `.xlsm` / `.docx` / RTF 编码的 `.doc`）：自研解析，不引第三方库；
  旧版**二进制** `.doc` 会提示另存为 `.docx`——二进制格式解析的投入产出比太低。
- **手动录入**：`weekMask` 用位图存周次，手动录入与导入走同一套入库逻辑。

曾经支持的纯文本粘贴、`.txt`/`.csv`/`.html` 导入都已移除：格式太多，每种都要独立测试，
而实际使用中九成是教务导出的 Excel/Word。

## 三、资讯抓取的现实约束

- **正文容器靠启发式**：按站点模板依次尝试 `#vsb_content` → `div.v_news_content` →
  `.conlis .cen` → `.conlis` → `article`。换模板就会失配，所以顺序不能随意调整。
- **图片要过滤**：排除 `cenr/side/right/recommend/footer` 等噪声容器、宽≤160 或高≤80 的小图、
  以及非 `/__local/` 却含 `/images/` 的模板图。不过滤会抓到整排侧栏横幅。
- **分页不是时序**：`/ndyw/2.htm` 会返回 2005 年的内容。因此开学时间识别**只在栏目首页**找线索，
  不能靠翻页回溯。

## 四、开学时间为什么保留手动入口

自动识别（抓「开学/开课/校历」类文章，从正文或发布日期推断第一周周一）在学期开始时有效，
但学期开始距今较远时线索会沉到分页深处，识别不到。

所以设计成：**手动改过就标记 `manual`，自动结果不再覆盖**；想重新识别就再点一次「自动识别」。
这是"自动优先但不强加"的折中。

## 五、校历为什么是人工结构化

校历以**通知或图片**形式发布，没有可机读接口，爬虫只能拿到一句"详见附件"。

做法：人工结构化进资源包（`calendar/<school>_calendar.json`），每年两次维护；
`verified` 字段标记是否已与教务处原文核对，未核对的学年在页脚红字提示。

## 六、滑动性能：四条措施（仍然有效）

课表左右滑动是唯一的高频动画路径。

| 措施 | 说明 |
|---|---|
| 无嵌套滚动 | 课表铺满一屏，行高按可用高度反算（30–64dp），去掉 `verticalScroll` 包裹分页 |
| 绘制取代布局 | 网格线 `drawBehind` 一次画完；课程块由单个 `Layout` 统一 `place`；边框自绘 |
| 文案预计算 | 时间区间、周次标签在数据变化时算好，绘制阶段只读字段 |
| 文字节点合并 | 每块从 5 个 `Text` 合并为 2 个；单页文字节点约 140 → 60 |

**动效规格**：统一 `MotionSpecs.Decelerate = cubic-bezier(0.05, 0.7, 0.1, 1)`（起步即最大速度）；
Pager 吸附用 `tween(280)` 而不用默认 `spring()`（弹簧从 0 速起步，观感像"先加速"）。

**尺寸外置**：列宽/行高在分页外算一次传入，每页不再各带 `BoxWithConstraints`（SubcomposeLayout）。

**帧率声明**：`MainActivity` 通过 `preferredDisplayModeId` 请求最高刷新率，避免 LTPO 把非游戏应用压到 60Hz。

## 八、仍然成立的两条判断

1. **资源包只改参数，不改算法。** 远程能下发的是数据；解析逻辑、界面、动效一律随 APK。
   原因不是技术做不到，而是"远程可执行代码"等于把信任边界交给仓库之外。
2. **非官方工具的边界**：不登录、不采集、不调用学校私有接口。所有学校数据来自公开页面与
   用户自己导出的文件。

## 九、资源包"只向上兼容"：设计意图与实现的三处偏差

原始设计是**只向上兼容**：包不保证旧 App 能读，用了新结构就抬高门槛，旧版整包跳过
（`DEVELOPING.md` 的「`minAppVersion` 是硬门槛」）。但实现与文档在三处把它做成了向下兼容：

| 偏差 | 位置 | 后果 |
|---|---|---|
| 清单解析静默忽略未知字段 | `PackModels.kt` 全用 `optLong/optString/optInt` | 旧 App 读到新结构不报错，用缺省值凑合跑 |
| 发包默认门槛是历史值 | `publish-pack.sh` 的 `PACK_MIN_APP` 缺省 `3804` | 忘传环境变量 = 自动向下兼容，硬门槛变成"靠人记得" |
| 文档把两种情况揉成一句 | `ARCHITECTURE.md` 5.1 第 4 条 | 读起来是"新字段都该向下兼容"，边界没了 |

要区分的其实是两件事：

- **新增可选参数**（有默认值、旧行为等价）→ 不抬门槛，旧 App 照常吃内容。这是"内容热更"的价值所在。
- **改变已有结构或语义**（目录变了、字段含义变了）→ 必须抬门槛，旧 App 整包跳过。

0.39.3 起用 `schema` 把这件事自动化：结构版本超出 App 支持范围就整包跳过，不必每次靠人记得。
落地在 `PackCompatibility.kt`（纯函数判定）与 `ResourcePackChecker` 的结构闸门，
发包侧在 `publish-pack.sh` 自动抬门槛。

**注意 `schema` 对已装机的旧版无效**（它们不认识这个字段），历史欠账收不回来；
第一次带 `schema` 的包若要拦老版本，仍须同时抬 `minAppVersion`。

还有一条刻意不做的：**清单顶层字段白名单（出现未知字段即整包拒绝）**。它读起来最符合
"不向下兼容"，但代价是以后每加一个可选参数都要抬门槛，参数热更直接失效。
`schema` 是"只在结构真的变了才拒"，两者选的是后者。

另注：归档里"保留 `minApp=3815` 的包，让旧版继续拿到规则更新"是**历史实践**，
与上述设计意图存在张力。0.39.3 的 `schema` + 门槛自动抬是否取代它，见 `PENDING.md` 的待拍板项。

## 十、"只发包适配新学校"为什么现在做不到

不是参数不够多，而是**"表格结构"没有被数据化**。`PdfTableParams` 里有六个字段是
**算法选择器**（`columnEdge` / `cellSource` / `groupByCourseCode` / `namePrefixMerge` /
`multiCourse` / `dropAboveHeader`），每加一所学校 = 解析器里加一条分支 + 包里打开它。
四所学校已用掉四个开关，`cellSource=lines` 那条路径建了没人用。

三条硬边界：几何层只有两套定位算法；文本层假设 PDF 能取到字（扫描件直接空结果）；
语义层是固定流水线（`cellRegex` + 固定的字段抽取顺序）。

解法是数据化而不是可执行化：取词源抽象 → 几何/语义分层 → `layout` 声明化 → 准入规则。
**不下放脚本 / DEX / 表达式求值** —— 那等于把信任边界交给仓库之外，与本项目"不碰私有接口"
的定位冲突。五步拆解见 `PENDING.md` 第零节。

## 十一、宁大教务 PDF 的三个坑（0.39.4）

宁大的 PDF 课表一直没适配过（只支持 Excel/Word）。补规则时踩到三处，都不是"调个参数"能过的：

1. **表头左上角的裸「星期」是角标，不是一列。** 按"以锚点开头"取表头会把它算进锚点，
   于是所有课右移一天（周一被记成周二、周日被丢弃）。最难受的是解析"成功"，
   只是全错。判据改成"与锚点完全相等的片段跳过"（`TextFragment.isColumnAnchor`）。
   湘大/民大的表头没有这一格，所以这条改动对它们无影响。
2. **格子里没有 `(3-4节)` 的括号。** 写的是 `1-17周,星期2,3-4节,北区…`，
   老的"按括号锚点回溯"切不开一格多课，第二门静默消失。新增
   `tuning.courseStartMarker`，按课类型前缀（`【理论】/【实验】/【上机】/【实训】`）切。
3. **续表页会把同一门课再画一遍**（样本第 2 页整页只有这一门）。导入时按
   名称+星期+节次+周次+教师+地点 去重 —— **键里必须带教师与地点**，
   否则"周五两个实验室同一时段"会被并成一条。

另外记一条回退的语义：**回退 = 切版本 + 把被放弃的版本记成"内容不合格"**。
只切版本不行 —— 1 小时后自动检查发现远端更高，会把用户拉回坏包，按钮等于没生效。
记进 `failedVersion` 正好复用已有的 24 小时重试窗口。
