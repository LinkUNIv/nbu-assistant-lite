## 二、按主题归档

### 资源包通道（0.38.7 完成）

- 分发：`packs` 分支 + `raw`/`jsDelivr` 双源；清单 `release/latest-<channel>.json`，包内逐文件 sha256。
- 校验 `PackGuards`：入口/资讯的域名白名单、学校规则、学校清单；**整包原子**（一个文件不合格整包拒）。
- 应用：`ResourcePackStore.apply` 落盘 + 版本只升不降 + 失败版本记 24 小时重试窗口。
- 内置包自 0.38.4 起清空（`assets/` 只留空壳），学校数据全部来自资源包。

### 文案整理（0.38.10 完成部分）

- 学校名参数化：`NewsScreen` 的 `removePrefix("宁波大学")`、版权句、认证页标题与域名都改成读 `rules`。
- 导入入口：按钮改「① 导入文件」、格式说明移到按钮下方小字、删掉从未引用的 `EmptyTimetablePanel`。
- 空态：资讯无栏目时不再显示空白页，改为「该校暂未提供资讯」。

### 公告通道（0.38.20 完成）

- 数据：`pack-src/announcements.json` → `Announcements.parse()` **逐条校验**，单条不合格只丢该条（与整包原子策略刻意不同）。
- 三档 `severity`：`silent` 只进列表、`banner` 亮红点、`blocking` 启动自动展开一次（不阻断操作）。
- `revision`：已读键 `id@revision`，改正文即可让老用户重新看到。
- 边界（写死）：纯文本、链接限 https、**禁止指向 .apk**、正文 ≤500 字、不承载"立即安装"指令。
- 兼容：旧包 `level`（info/important/critical）映射为 silent/banner/blocking。

### 课程叠放（0.38.20 完成）

- `CourseStacking.groupsOf()`：同天 + 节次区间相交即同组（传递合并），**不做数据迁移**，旧数据打开即适配。
- 渲染：层叠 5dp 错位 + 右上角门数角标；点击弹 `CourseStackSheet` 选一门。
- 调课：冲突时新增「仍然调整」（两门共存），「替换原课程」降为次选。
- 连带：摘要与小组件显示「等 N 门」；提醒本来就用 `sameTimeCount` 输出「另有 N 节同时开始」，无需改。

### 切校入口回退（0.39.3 完成）

0.39.2 把学校列表做成「关于页常驻列表」，四所学校平铺、点一行即切。实测代价大于收益：

- 切校会整体替换规则 / 作息 / 白名单 / 资讯 / 入口，是**全局高风险动作**，且即时生效、无二次确认。
- 课表按学期存放、并未按 `schoolId` 隔离（见 `PENDING.md` 第四节），切过去看到的仍是同一份课表，
  用户的第一反应是"课表丢了"。
- 常驻列表把"两次点击的低频动作"变成"一次点击的日常按钮"，误触概率上升。

回退做法：删掉「版本行连点 5 次解锁」（`SchoolPreference.KEY_UNLOCKED`/`isUnlocked`/`unlock` 一并移除），
关于页无条件显示「当前学校 + 切换」，选择收进 `AlertDialog`；当前项标（当前）且不可点。

设计意图留档：**切校是小众需求，入口可以显眼，但操作必须"多一步"** —— 多那一步就是确认。

## 三、历史决策（不要重新讨论）

| 决策 | 理由 |
|---|---|
| 不做脚本/DEX 动态加载解析器 | 远程代码执行面，与"资源包只改参数"冲突；识别版式靠 OCR 而非脚本 |
| 公告不得作为 APK 下载口 | 绕过 sha256 校验等于给钓鱼开口 |
| 小程序/商店强制更新不做 | 未上架；走 GitHub Release + 自更新 |
| ML Kit 不做按需下载 | GitHub 分发 + 离线可用，"第一次用不了"更严重 |
| 保留 `minApp=3815` 的包 | 让旧版继续拿到规则更新；公告文件对旧版是惰性的 |
| 第 3 字节版本号（修订位）自行推进 | 主位变更需用户确认 |

## 四、踩过的坑（避免重犯）

| 坑 | 症状 | 处理 |
|---|---|---|
| 中文路径 | `testPreviewUnitTest` 全部 `ClassNotFoundException`，`assemble` 正常 | 单测在纯 ASCII 目录或 CI 跑 |
| Kotlin 编译卡死 | `compilePreviewKotlin` 十分钟无输出 | 先怀疑环境；绕法是推 main 让 CI 编译 |
| `String.replace` 未断言 | 静默没命中，编译时报"没有这个字段" | 改代码一律 `assert`，锚点带函数上下文 |

| 内联 python 引号嵌套 | `purge-cdn.sh` 语法错误 | 脚本写完当场跑一次 |
| 变量同名误替换 | `latestCode` 在两个函数里都有，替换命中错的 | 锚点带上函数上下文 |
