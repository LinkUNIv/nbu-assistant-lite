# 已决（不做 / 暂缓）

| 项 | 结论 | 理由 |
|---|---|---|
| 系统通知推送更新 | 不做 | 渠道关闭、免打扰、权限被拒一串分支，打开频率够用 |
| 「本次更新内容」独立入口 | 不做 | 与更新日志页重复 |
| 脚本 / DEX 动态加载解析器 | 不做 | 远程代码执行面；识别版式靠 OCR 而非脚本 |
| 公告作为 APK 下载口 | 不做 | 绕过 sha256 校验等于给钓鱼开口 |
| ML Kit 按需下载 | 不做 | GitHub 分发 + 离线可用优先，"第一次用不了"更严重 |
| 第三方下载镜像（ghproxy 一类） | 不做 | 不可控；将来只考虑自建静态镜像 |
