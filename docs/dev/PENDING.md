# 零、主线：让"新学校只发资源包"

> **结论：现在做不到，不是因为参数少，而是"表格结构"这件事本身没有被数据化。**
> `PdfTableParams` 里的 `columnEdge` / `cellSource` / `groupByCourseCode` / `namePrefixMerge` /
> `multiCourse` / `dropAboveHeader` 都是**算法选择器**，不是参数。每加一所学校 =
> 在解析器里加一个 `if` 分支 + 在 `rules.json` 里打开它。
>
> 现状：nbu 全默认 / xtu 开 `namePrefixMerge` / csmy 全默认 / scmzu 开 `center` +
> `groupByCourseCode` + `namePrefixMerge` + `multiCourse`。四所学校用掉四个开关，
> 而 `cellSource=lines` 那条路径建了没人用。这条路已到边际。

五步，跨 0.39.3 → 0.43：

- [x] **① 能力协商**：包声明结构版本（`schema`），App 声明支持到几，超了整包跳过 → 0.39.3 已完成
- [ ] **② 取词源抽象**：现在 OCR 只是"取词为空时的兜底"（`PdfOcrExtractor`），
      与文本层两套口径、参数不共享。把它提成可切换的取词源，几何层不感知 → 0.42.0。
      **不做这条，扫描件学校只能靠兜底糊过去**
- [ ] **③ 几何层与语义层分离**：几何层只产出 `Cell(day, top, bottom, text)`，
      语义层只吃 Cell 造课。现在 `parse()` 一边定位一边造 `ParsedSlot`，两件事缠在一起 → 0.42.0
- [ ] **④ 布局声明化**：`columns / rows / region / cells` 四个维度用数据描述，
      替代互斥布尔。新增版式尽量落在组合空间里，落不进去才发版 → 0.43.0
- [ ] **⑤ 准入规则**：新学校必须带脱敏夹具 + `selftest.json` 且能跑通才收 → 0.43.0 起执行

**硬边界（`NOTES.md` 第八节）**：包里下发脚本 / DEX / 表达式求值器一律不做，
那是远程代码执行面。**声明化 ≠ 可执行化。**

# 已决（不做）

| 项 | 理由 |
|---|---|
| 包内下发脚本 / DEX / 表达式求值 | 远程代码执行面；**声明化 ≠ 可执行化** |
| 发包时扫描"未知字段" | 要维护一份随代码变动的字段白名单，误报多于真报；真正的风险（结构变了旧版读不懂）已由 `schema` 拦住 |
| 清单顶层字段白名单（未知即拒） | 等于每加一个参数都要抬门槛，参数热更失效；用 `schema` 只拦结构变更 |
| 系统通知推送更新 | 渠道关闭、免打扰、权限被拒一串分支 |
| 「本次更新内容」独立入口 | 与更新日志页重复 |
| 公告作为 APK 下载口 | 绕过 sha256 校验等于给钓鱼开口 |
| ML Kit 按需下载 | 离线可用优先 |
| 第三方下载镜像 | 不可控 |
