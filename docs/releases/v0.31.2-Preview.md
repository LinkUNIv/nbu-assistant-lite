# 0.31.2 Preview

发布日期：2026-10-29

本次新增应用内更新日志。此前要了解某个版本改了什么，只能回仓库翻 `CHANGELOG.md`；
现在「我的 → 关于 → 更新日志」即可查看，内容与该文件完全一致。

## 变更记录直接取自仓库

更新日志页没有自己的文案。构建时仓库根目录的 `CHANGELOG.md` 被复制进安装包，
页面读取后按 Markdown 解析。因此**写变更记录就等于写应用内文案**，不存在两处不同步的问题。

代价是这份文本会随包分发：当前约 145 KB，压缩后十几 KB。

## 排列与折叠

版本按倒序排列，最新在前，当前安装的版本标注「当前」。

最近 6 个版本直接铺开内容；更早的收成一行，点开即读。变更记录已累积 94 个版本，
全部展开会让「这个版本改了什么」更难回答，因此首屏只给最近的几次。

## 排版处理

- 版本号与渠道（Preview / 正式版）分开排字，日期靠右
- 分组标题（`### 一、…`）与条目列表按层级缩进，列表项前加圆点
- 行内强调与等宽代码按 Markdown 规则渲染，不再出现原始的星号与反引号
- 表格拍平为逐行文字：手机屏宽放不下真正的表格，横向滚动也更难读
