# 0.32.0 Preview

发布日期：2026-10-30

本版新增桌面小组件，首版提供 2×2 的「下一节」卡片。

## 小组件

显示下一节课的倒计时、课程名称、上课时间与教室。上方为倒计时，下方为课程信息，两块之间留出间隔。

课名前的课程代码不再显示。

倒计时的分钟数用红色显示，字号大于组件内的其余文字。课程已经开始但尚未结束时，显示「正在 上课」。

## 尺寸

提供 2×2 一种尺寸，宽度可占 2 格。4×2 与 2×4 在 0.32.1 提供。

## 刷新

应用内课表变动后自动刷新。系统每 30 分钟刷新一次，作为兜底。

## 已知问题

- 只有 2×2 一种尺寸，4×2 与 2×4 尚未提供
- 小组件不支持亚克力材质，只有纯色背景与圆角
- 圆角在 Android 12 以下不生效
- 上下课时刻不会立即刷新，最长滞后 30 分钟
- 仅在 MIUI 桌面验证过，其他桌面的尺寸吸附与刷新行为未测试
