# 0.32.1 Preview

发布日期：2026-10-30

本版调整小组件的版式，尺寸与功能不变。

## 版式

倒计时占据组件上半部分，「下一节」与分钟数贴近顶部；课程信息贴近底部，两块各占一头。

「下一节」改用正文颜色，与课名一致。

分钟数加大到 42sp 并加粗，单位「分钟后」移到数字下一行。同一行放不下更大的数字。

课程名称加粗。

## 已知问题

- 只有 2×2 一种尺寸，4×2 与 2×4 尚未提供
- 小组件不支持亚克力材质，只有纯色背景与圆角
- 圆角在 Android 12 以下不生效
- 上下课时刻不会立即刷新，最长滞后 30 分钟
- 仅在 MIUI 桌面验证过，其他桌面的尺寸吸附与刷新行为未测试
