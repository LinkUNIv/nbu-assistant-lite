# 0.33.0 Preview

发布日期：2026-10-31

本版新增应用内检查更新，不再需要手动下载安装包。

## 检查更新

「我的 → 关于」新增「检查更新」入口，显示当前版本。

点击后查询最新版本。有新版本时显示版本号，再次点击开始下载。下载完成后交给系统安装器，由系统确认安装。

下载过程显示百分比。安装包在交给系统之前校验 SHA-256，校验不通过则取消并删除。

## 分发

每个版本在发布页附带一份清单，记录版本号、安装包地址与校验值。应用读取这份清单判断是否有新版本。

清单随发布生成，因此「是否有新版本」以已经发布的版本为准。

## 已知问题

- 需要系统允许「安装未知应用」，未开启时点击安装会失败并提示
- 检查更新与下载都依赖 GitHub，网络受限时可能超时或失败
- 不会自动检查，需要手动点击
- 本版未在真机上验收
- 首次使用本版时，上一版没有清单文件，检查会提示无法获取版本信息
