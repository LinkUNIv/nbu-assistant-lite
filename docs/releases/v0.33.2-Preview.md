# 0.33.2 Preview

发布日期：2026-10-31

本版更换签名证书，修正应用内更新装不上的问题。

## 签名

此前的每个版本都用不同的证书签名。装好一个版本之后，下一个版本会被系统拒绝安装，界面显示「安装失败(-7)」，原因一栏写着「与已安装应用签名不同」。应用内更新因此从未成功过。

现在所有版本改用同一份固定证书，之后的更新可以覆盖安装，不需要卸载。

## 更新入口

检查更新在下载完成之后、交给系统安装器之前，先比对新包与本机已安装版本的签名。两者不同时直接提示「与已安装版本签名不同，需先卸载再安装」，不再等到系统弹出带错误编号的失败页。

## 已知问题

- **从任何旧版本升级到本版，都需要先卸载一次**。旧版本的证书无法复用，这是最后一次需要手动卸载
- 卸载会清除应用数据，课表需要重新导入
- 安装需要系统允许「安装未知应用」
- 本版未在真机上验收
