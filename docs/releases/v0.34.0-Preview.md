# 0.34.0 Preview

发布日期：2026-10-31

本版新增资源包更新：校历与入口列表可以不必装新版就更新。

## 资源包

应用会读取一份独立的资源清单。清单里的版本比本机新时，自动下载并应用，不弹窗、不需要安装。生效范围是校历与「入口」页的链接列表。

应用内始终保留一份内置资源。下载的包校验不通过、结构不符或写入失败时自动退回内置，不影响启动。检查在启动后十秒进行，网络不通只是这次跳过，不会记录失败。

## 校验

- 每个文件按清单中的 sha256 核对，不符即整包拒绝
- 包中声明所需的最低应用版本，低于该版本的安装整体跳过，不做部分应用
- 只接受比本机更新的包，旧包不会被应用
- 同一版本应用失败后不再重试
- 入口链接不允许出现内置清单之外的域名，非 https 一律拒绝

## 调试面板

「调试面板」新增资源包一栏，显示当前版本、来源（内置或远端）、上次检查时间，并提供手动检查。

## 已知问题

- 资讯源与课表解析词典仍未外置，仍在代码内
- 下载源为 GitHub 与 jsDelivr，网络受限时可能取不到，此时继续使用内置资源
- 本版未在真机上验收
