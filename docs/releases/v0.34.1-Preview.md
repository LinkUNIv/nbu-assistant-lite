# 0.34.1 Preview

发布日期：2026-10-31

本版把资讯栏目与抓取规则移出代码，改为可随资源包更新。

## 资讯来源

栏目列表（名称、地址、来源署名）与正文抓取规则原先写死在代码里。现在这份内容放在一份配置中，内置一份，资源包可以覆盖。学校给栏目改名、更换栏目地址，或新闻网改版换了正文容器的标签，不必等发版。

## 校验

- 配置结构不合格时整份退回内置：栏目为空、链接非 https、正则无法编译
- 栏目地址不允许出现内置配置之外的域名
- 应用资源包时校验一次，读取配置时再校验一次

## 已知问题
