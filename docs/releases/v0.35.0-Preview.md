# 0.35.0 Preview

发布日期：2026-10-31

本版修正资源包检查取不到新版本的问题，并把更新提醒集中到「关于」页。

## 资源包

此前检查资源包时，清单文件经由 CDN 读取，而 CDN 会缓存分支内容。实测新资源包发布两小时后，检查仍读到上一版的清单，界面因此显示「已是最新」。现在清单改为直接读取源站，文件下载仍经由 CDN。

下载源增加到四个，某个源失败时自动换下一个；同一次检查中一旦某个源可用，后续文件优先复用它。

## 新闻页

日期块此前宽度固定，「10.31」这类日期的末位会被裁掉。现在按文字实际宽度自适应，不再截断。

## 关于页

「关于」拆成三栏：

- 版本：当前版本、检查更新
- 资源：资源包版本、来源、上次检查、手动检查
- 文档：开源许可、更新日志

调试面板保留手动检查，作为排障手段。

## 更新提醒

- 启动后十二秒自动检查一次版本，二十四小时内最多一次
- 发现新版本时弹窗，正文为该版本的完整说明，可滚动阅读
- 点「以后再说」后同一版本不再弹窗，但「关于」入口的红点保留
- 资源包发现新版本同样在「关于」亮红点，进入「资源」栏后熄灭

## 已知问题

- 版本检查依赖 GitHub 接口，网络受限时会失败；失败不记为「已检查」，下次启动会重试
- 本版未在真机上验收
