# 0.35.1 Preview

发布日期：2026-10-31

本版修正资源包应用失败后无法恢复的问题。

## 资源包

上一版把「下载失败」与「内容不合格」当作同一种失败。一次连接中断就会让该版本被永久跳过，之后无论自动检查还是手动点击，都只返回「已跳过」。

现在区分两类：

- 网络原因（源不可达、连接中断、返回错误状态码）不记为版本失败，下次检查会重新尝试
- 内容原因（校验不符、配置被拒、写入失败）才记为失败，六小时后允许重试

## 失败原因可见

「资源」栏直接显示失败原因与具体文件，例如「下载失败：HTTP 404 @fastly.jsdelivr.net [portal/entries.json]」。同一行同时写入 `pack/last-error.txt`，重启后仍可读取。

## 重试

存在失败记录时，按钮显示为「重试」，无视间隔限制与失败标记，强制检查一次。

## 检查时间

「上次检查」改为显示最后一次**尝试**的时间，不再是最后一次成功的时间。自动检查限制为每小时一次。
