# 0.35.25 Debug

记录考勤学生页面的 pointerdown/up、click、input/change、focus、键盘事件及目标、父链、时间顺序。网页数字按钮无需系统输入法也能捕获。记录加载、路由变化、交互前后 DOM 快照，以及节点增删、属性和文字变化，元素使用稳定编号。快照含元素文字、基础属性、坐标、可见性和伪元素内容。大型 DOM 事件分片编号，不静默裁掉页面尾部。

延续 0.35.24 考勤接口记录，JSON 接口正文仍有约 64K 单事件上限及截断标记。日志两份各约 50MB 滚动，旧内容可能淘汰；复现后及时导出。密码、隐藏输入、令牌字段仍隐藏。无法保证捕获原生桥、Service Worker、Canvas 内部状态或跨域 iframe。详细诊断会增加运行负担。
