# 0.35.29 Debug

应用前台打开或恢复时检查课表；区间为首节开始前 15 分钟（含）至末节结束（不含）。排除明日课程、停课和调课占位。前台每 30 秒重新检查区间。静默使用共享 Cookie 的不可见 WebView，复用保存账号自动登录，每个预加载实例最多尝试一次。需要二次验证时不自动完成。离开应用前台释放 WebView，非后台常驻服务。

课程名忽略空白后精确匹配，且学校组件确认 coursePlanId 存在、attendanceState 为 0 才动态提示点名。预加载不自动进入课程及不提交签到。课程列表使用学校加载时的数据，不保证在教师随后发起考勤时实时刷新；再次打开点名可刷新。构建与现有测试通过，需真机验证隐藏登录和跨页面会话共享。
