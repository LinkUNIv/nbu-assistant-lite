# 0.35.35 Debug

签到页新增相机自动验证入口。使用 CameraX 后摄预览和内置 ML Kit 中文 OCR（不依赖 Play 服务下载模型）。将签到码标签及数字放在中央框附近；旋转校正、中央区域裁剪、放大并交替使用原色/灰度对比增强。优先标签关联，避免日期和长学号，歧义不提交。三次连续识别同码后，按学校原按钮依次执行重置、四位数字和确认，不使用手机输入法，不构造旁路签到接口。

每个相机识别会话同一码只尝试一次；学校拒绝后等 2.5 秒识别新码，未收到结果时等待而不重复提交。用户停止或应用退到后台会取消尚未发出的按键；已提交的网络请求不能撤销。收到成功响应停止并回到签到页。图像仅内存处理，不写日志、不保存、不上传；详细诊断日志仍记录输入的签到码。模型内置使 APK 体积增加。

已运行现有测试及新增 OCR 候选规则测试；未完成真机取景、示例照片识别率、按钮时序和学校反馈全流程验证。倾斜、反光、模糊或目标太小可能无法识别，请调整距离。
