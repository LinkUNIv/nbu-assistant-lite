# 0.35.49 Preview

本次为预览版本，汇总课表、小组件、账号及点名功能更新。包名 `app.nbult.lite.preview`，版本码 `3549`，Android 7.0 及以上可安装。已启用 R8 和资源压缩，未启用调试。与 Debug、Release 可并存，数据互不共享；首次切换通道需自行导入课表并保存账号。

## 更新内容

- 课表支持周一或周日为一周第一天，修正跨周日课程定位；记住折叠和显示状态，课程设置改为长按打开。
- 修正课程地点显示、文本截断和侧栏高亮；小组件显示完整连续节次时间，支持倒计时、刷新、点击课程定位及空白打开应用。
- 4×2 小组件顶部中央新增签到入口，列表按桌面实际尺寸布局，课程不足时空白可点击，课程较多时可滚动。
- “我的 → 账号”可在本机加密保存账号密码，支持更改与清除，不提供保存密码查看功能。
- 点名直接进入学校考勤课表，登录页和二次验证码页使用应用主题界面；认证页面等待加载完成后处理，课程列表继续提前检测和自动跳转。
- 长按点名进入设置，可切换课程列表 UI、唯一开放课程自动进入和后台预加载；预加载开启时同时开启自动跳转。
- 在本地课表的开课前 15 分钟至下课前，应用前台可静默预加载并尝试保存账号登录。红色表示未就绪，绿色表示认证课程数据已获取，匹配开放课程动态高亮。点击高亮入口可接管已有网页。
- 签到页使用四位数字格与应用内数字键盘，不唤起手机输入法；保留学校原网页继续入口。
- 新增相机 OCR 签到与独立 OCR 测试入口，支持双指缩放、点击对焦/测光和复位。优先定位蓝色环境中的黄色区域，裁图放大并增强蓝字，兼容泛白投影的低对比度处理。

## 使用与数据

- 课表可离线使用。点名需要学校网络服务；应用不替代学校身份校验，不自动完成二次验证码或设备信任确认。
- 相机识别为用户主动开启；图片仅内存处理，不保存或上传。识别到符合条件的四位数字后通过学校原按键提交，同码去重，等待响应时不并发重复提交，成功停止。
- 预览版保留基础本地交互诊断；Debug 的接口正文、网页输入和完整 DOM 诊断未在 Preview 启用。导出日志前仍应检查个人信息，勿直接提交到公开 Issue。
- 清除或更改账号会清理点名浏览器会话。卸载应用会删除本地数据；升级请使用相同包名及签名。

## 已知限制

- OCR 为实验功能。泛白样本已验证颜色定位和增强，但同机离线对比尚未完整识别四位码，不能保证准确率或签到成功；可先用 OCR 测试入口评估，再使用手动输入。
- “后台预加载”当前指应用前台中的不可见浏览器，并非离开应用后常驻的后台服务；课程状态基于学校已加载的数据，未实现持续向服务器刷新。
- 学校网页结构、会话策略和验证码形式变化可能影响适配，必要时选择学校原页面继续。UA 不等同于今日校园原生桥。
- 此版本不包含曾回退的分阶段课表启动优化，启动等待问题仍需进一步实机诊断。

## 构建与校验

构建命令：`./gradlew :app:testPreviewUnitTest :app:assemblePreview`。发布资产包含 Preview APK、源码 ZIP、SHA-256 校验文件和应用内更新清单；混淆映射另行归档用于崩溃分析。源码不含签名密钥、本机配置、私有课表或 OCR 原始照片。校验值以发布资产 `SHA256SUMS.txt` 为准。
