# 0.36.0 Preview

包名 `app.nbult.lite.preview`，版本码 `3600`，Android 7.0（API 24）及以上可安装。
已启用 R8 与资源压缩，未启用调试。与 Debug、Release 可并存，数据互不共享；
首次切换通道需自行导入课表并保存账号。

## 本次变化

- 安装包由 45 MB 降至约 23 MB：只保留 `arm64-v8a` 与 `armeabi-v7a` 两个架构，
  移除 x86 / x86_64 的 OCR 原生库。
- 工作日志可导出点名模块记录：浏览器打开、页面加载完成、纠回课表、HTTP 错误、
  网络错误、证书错误六类事件同时写入工作日志；DOM 与接口正文仍只进点名专用日志。
- 工作日志每行带会话标识与四位序号，导出文件开头标注本次会话编号，便于按顺序还原一次运行。
- 工作日志新增地址脱敏：只保留协议、域名、端口与路径，查询参数与片段不入日志。
- 访问学校页面的 User-Agent 改为固定前缀加可调版本号，浏览器与预加载共用同一来源。
- 关于页与 README 的说明改为「课表不需要登录，点名与账号需要学校统一认证」，
  并注明登录仅在本机浏览器内完成、凭据不经过应用服务器、默认不保存。
- 版本号 0.35.49 → 0.36.0。

## 功能要点（含 0.35.13 以来累积内容）

- 课表支持周一或周日为一周第一天；记住折叠与显示状态；课程设置改为长按打开。
- 桌面小组件显示完整连续节次时间，支持倒计时、刷新、点击课程定位、空白处打开应用；
  4×2 顶部中央新增签到入口，列表按桌面实际尺寸布局。
- 「我的 → 账号」可在本机加密保存账号密码，支持更改与清除，不提供保存密码查看。
- 点名直接进入学校考勤课表；登录页与二次验证码页使用应用主题界面；
  认证页面等待加载完成后处理，课程列表提前检测并自动跳转。
- 长按点名进入设置：课程列表 UI、唯一开放课程自动进入、前台预加载。
  预加载在开课前 15 分钟至下课前于应用前台运行，红色未就绪、绿色已取得认证课程数据。
- 签到页使用四位数字格与应用内数字键盘，不唤起系统输入法；保留学校原网页继续入口。
- 相机 OCR 签到：优先定位蓝色环境中的黄色区域，裁图放大并增强蓝字，
  兼容泛白投影的低对比处理；支持双指缩放、点击对焦与测光、复位。

## 使用与数据

- 课表可离线使用。点名需要学校网络服务；应用不替代学校身份校验，
  不自动完成二次验证码或设备信任确认。
- 相机识别为用户主动开启；图片仅内存处理，不保存或上传。识别到符合条件的四位数字后
  通过学校原按键提交，同码去重，等待响应时不并发重复提交，成功停止。
- 预览版保留基础本地交互诊断；Debug 的接口正文、网页输入与完整 DOM 诊断未在预览版启用。
  导出日志前仍应检查个人信息，勿直接提交到公开 Issue。
- 清除或更改账号会清理点名浏览器会话。卸载应用会删除本地数据；升级请使用相同包名及签名。

## 已知限制

- OCR 为实验功能。泛白样本已验证颜色定位与增强，但同机离线对比尚未完整识别四位码，
  不能保证准确率或签到成功；可先用 OCR 测试入口评估，再使用手动输入。
- 「后台预加载」指应用前台中的不可见浏览器，并非离开应用后常驻的后台服务；
  课程状态基于学校已加载的数据，未实现持续向服务器刷新。
- 学校网页结构、会话策略与验证码形式变化可能影响适配，必要时选择学校原页面继续。
- 安装包仍含约 10 MB 的 OCR 原生库与模型，无法进一步压缩而不牺牲离线识别。

## 构建与校验

构建命令：`./gradlew :app:testPreviewUnitTest :app:assemblePreview`。
发布资产包含 Preview APK、源码 ZIP、SHA-256 校验文件与应用内更新清单；
混淆映射另行归档用于崩溃分析。源码不含签名密钥、本机配置、私有课表或 OCR 原始照片。
校验值以发布资产 `SHA256SUMS.txt` 为准。
