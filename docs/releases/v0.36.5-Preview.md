# 0.36.5 Preview

包名 `app.nbult.lite.preview`，版本码 3605，Android 7.0 及以上。使用现有 Preview 签名，启用压缩和优化。

## 更新内容

- 修复签到数字转发误点已输入数字的问题，只操作学校数字键盘，逐个确认网页实际输入后更新遮罩。
- 四位数字输入完整后自动提交；提交失败、网络错误或超时后重置输入。手动与相机识别共用输入链路。
- 学校返回签到成功后自动回到课程列表，停止识别、清除点名高亮，避免重复自动进入。
- 前台预加载课程列表每 15 秒刷新，匹配当前课程开放签到后在后台进入签到码页面，点击高亮点名按钮复用网页。
- OCR 测试入口移至长按点名打开的点名设置页。
- 4×2 小组件地点保留右侧单行位置，字号增至 11sp，移除括号内补充内容并收紧列间距。

## 验证与限制

Debug 构建和数字输入、网页观察器回归检查通过；Preview 在 GitHub Actions 运行对应单元测试与构建。实际学校登录、开放签到和桌面布局仍需真机验证。

预加载仅在应用前台、当前课程开课前 15 分钟至下课前运行，需要开启后台预加载设置。15 秒刷新不保证实时收到老师的操作。OCR 对泛白投影的完整四位识别仍存在限制。超时不代表服务器一定未签到，请关注学校返回状态。

Preview 与 Debug、Release 数据隔离。源码 ZIP、安装包、混淆映射和校验文件随发布提供；本机账号、Cookie、私有照片与日志不包含在源码包中。
