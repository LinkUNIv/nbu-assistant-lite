# 0.37.0 Preview

包名 `app.nbult.lite.preview`，版本码 3700，Android 7.0 及以上。使用现有 Preview 签名，启用压缩和优化。

## 更新内容

- 检查到新版本后立即记录该版本的更新说明，与下载、安装完全解耦：取消更新、下载失败、安装失败或杀掉进程都不会丢掉这条记录。
- 装上的版本与记录对得上时，启动后弹出「已更新到 x.y.z」并展示这一版的说明；展示过的内容移到「关于 → 文档 → 本次更新内容」，之后可以随时回看。
- 签到提交、成功、失败、超时四类事件写入工作日志，导出日志即可判断一次签到卡在哪一步。日志只记结果，不记签到码。
- 自动进入签到改为按课程抑制。此前是一个一次性的开关，进过一次之后整次会话都不再自动进入，当天后面几节课要手动点；现在只抑制触发过的那一门课，该课不再开放签到时自动解除。手动点过的课也算进过，避免签到失败退回列表后又被弹回同一门课。
- 构建流程增加 `tools/test-sign-input.cjs` 的回归检查，与既有的观察器回归一起跑。此前这份测试只在本地执行过。
- 更新日志标题统一带回通道后缀；历史条目按 `docs/releases/` 里的发布说明逐条核对后补写，无法核实的 5 条保持原样不作猜测。

## 验证与限制

本机在纯 ASCII 路径下完成 `:app:testPreviewUnitTest`（19 项，0 失败）、`node tools/test-sign-input.cjs`、`node tools/test-browser-observer.cjs` 与 `:app:assemblePreview`；Preview 在 GitHub Actions 运行同一组检查与构建。

更新提醒的持久化逻辑新增了三个偏好键，未做迁移以外的数据变更；从 0.36.x 覆盖升级后，本次更新内容需要在下一次检查到新版本并安装后才会有记录，属预期。

「本次更新内容」只有在经由应用内更新装上的版本才有内容；从外部直接安装 APK 时该入口显示无记录。

实际学校登录、开放签到与桌面布局仍需真机验证。预加载仅在应用前台、当前课程开课前 15 分钟至下课前运行，需要开启后台预加载设置；15 秒刷新不保证实时收到老师的操作。超时不代表服务器一定未签到，请以学校返回状态为准。

Preview 与 Debug、Release 数据隔离。源码 ZIP、安装包、混淆映射和校验文件随发布提供；本机账号、Cookie、私有照片与日志不包含在源码包中。
