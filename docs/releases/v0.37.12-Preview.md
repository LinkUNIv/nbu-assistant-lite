# 0.37.12 Preview

包名 `app.nbult.lite.preview`，版本码 3712，Android 7.0 及以上。使用现有 Preview 签名，启用压缩和优化。

## 更新内容

**课前提醒的时间校验**

- 提醒触发时会核对距上课还剩多少时间：超过 90 分钟判定为排程异常，不通知，并记录日志。此前出现过提前十几个小时触发的情况，需要修复。
- 闹钟触发时同时记录与预定时刻的偏差，便于区分「系统延迟投递」与「排程本身算错」。

**更新检查的记录与表现**

- 未到检查间隔时也会写日志，并写明还剩多久；工作日志摘要新增「更新检查」一栏，不再出现「日志里完全看不到检查」的情况。
- 更新说明底部的渐隐与弹窗底色对齐，长说明滚动时不再有一条浅色接缝。
- 自动检查与手动检查共用同一通道，同一时刻只发起一次请求。
- 资源包检查跳过时写明距上次多久。

## 验证与限制

本机在纯 ASCII 路径下完成 `:app:testPreviewUnitTest`（32 项）与构建；Preview 在 GitHub Actions 运行同一组检查与构建。

本版只增加校验、日志与显示修正，不改动提醒的排程规则：正常的课前 30 / 15 分钟提醒不受影响。真机上需要确认正常提醒仍按时触发一次；若日志里出现「闹钟早到」，说明排程仍有问题，需要按偏差值继续查根因，而不是把阈值调宽。

点名页的退出按钮、WebView 交还预加载与深色模式切换闪烁仍在后续版本处理。

Preview 与 Debug、Release 数据隔离。源码 ZIP、安装包、混淆映射和校验文件随发布提供；本机账号、Cookie、私有照片与日志不包含在源码包中。
