# 0.37.13 Preview

包名 `app.nbult.lite.preview`，版本码 3713，Android 7.0 及以上。使用现有 Preview 签名，启用压缩和优化。

## 更新内容

**退出与返回**

- 顶栏左侧改为「关闭」，点一次回到课表，不再需要连按几次后退。
- 「网页后退」「刷新」「导出日志」「用系统浏览器打开」收进「更多」菜单。
- 系统返回键：停在课表页时按一次直接退出；在考勤站其它页面仍是网页后退，不会把人踢出整个点名。

**预加载优化**

- 退出点名时不再立即销毁网页。只要还停在考勤站、且不在认证页，页面会交还预加载，下次进入不必重新加载整个应用。
- 认证页不交还：那里带着表单与证书状态，留在后台既没用也不安全。

**站内跳转优化**

- 课程列表与签到页之间的切换改为立即判定。

## 验证与限制

本机在纯 ASCII 路径下完成 `:app:testPreviewUnitTest`（32 项，0 失败）、`node tools/test-sign-input.cjs`、`node tools/test-browser-observer.cjs` 与构建；Preview 在 GitHub Actions 运行同一组检查与构建。

真机上需要确认三件事：退出再进入时网页不应重新加载；在签到页按系统返回应回到课程列表而不是退出；签到码输入不受影响。若预加载被关闭，退出时仍照旧销毁页面。

点名页的界面重做（10.3）与深色模式切换的剩余观察项仍在后续版本处理。

Preview 与 Debug、Release 数据隔离。源码 ZIP、安装包、混淆映射和校验文件随发布提供；本机账号、Cookie、私有照片与日志不包含在源码包中。
