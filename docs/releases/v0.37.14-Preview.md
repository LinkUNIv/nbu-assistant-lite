# 0.37.14 Preview

包名 `app.nbult.lite.preview`，版本码 3714，Android 7.0 及以上。使用现有 Preview 签名，启用压缩和优化。

## 更新内容

**应用内下载**

- 下载断线后保留已有数据无须重新下载。
- 连续中断会自动重试，最多三次；重试仍失败提示。
- 校验不通过会删除重下，不会交给系统安装。

**签到面板**

- 底部不再显示「学校按键尚未就绪，请稍候或查看原页面」。
- 按键识别失败时先自动重试；仍失败只记日志，不再打扰使用者。
- 「查看学校原页面」从面板底部移到顶部「更多」菜单，与「用系统浏览器打开」并列。前者在应用内显示原网页，后者跳到系统浏览器。

**日志**

- 点名页预加载不再每 15 秒重复写同一条匹配记录，避免把其它记录挤出上限。
- 手动检查更新在日志中单独标注，不再和自动检查的跳过记录混在一起。

## 验证与限制

本机在纯 ASCII 路径下完成 `:app:testPreviewUnitTest`（32 项，0 失败）、`node tools/test-sign-input.cjs`、`node tools/test-browser-observer.cjs` 与构建；Preview 在 GitHub Actions 运行同一组检查与构建。

断点续传依赖下载地址支持 `Range` 请求；若不支持会自动退化为从头下载，正确性不受影响。开机与切后台后的提醒重排逻辑未改动。

真机上需要确认三件事：断网再恢复后下载能接着走；签到页连按四位并确认能正常提交；「更多 → 用学校原页面」能切回原网页。

Preview 与 Debug、Release 数据隔离。源码 ZIP、安装包、混淆映射和校验文件随发布提供；本机账号、Cookie、私有照片与日志不包含在源码包中。
