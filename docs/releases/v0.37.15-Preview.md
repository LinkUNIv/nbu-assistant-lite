# 0.37.15 Preview

包名 `app.nbult.lite.preview`，版本码 3715，Android 7.0 及以上。使用现有 Preview 签名，启用压缩和优化。

## 更新内容

**更新流程优化**

- 检查到新版本立即弹出更新说明。
- 点一次「下载」即开始，不再先「检查」再「确认」两次操作；移动网络与 Wi-Fi 行为一致，不会静默下载。
- 下载完成后不自动弹出系统安装器，改为在弹窗与关于页显示「安装」，由用户决定安装时机。
- 关掉弹窗或重启应用后仍能安装：关于页会显示「可安装」，点一下即可。

**点名页优化**

- 应用切到后台再回来，不再重建签到网页。

## 验证与限制

本机在纯 ASCII 路径下完成 `:app:testPreviewUnitTest`（32 项，0 失败）、`node tools/test-sign-input.cjs`、`node tools/test-browser-observer.cjs` 与构建；Preview 在 GitHub Actions 运行同一组检查与构建。

预加载开启时，签到网页会常驻内存（不再只在课间挂载），用于换取切换页面时的即时响应；关闭「点名预加载」后不再占用。

真机上需要确认四件事：检查到新版本应立即弹窗且带体积；点一次即开始下载；下载完成后不自动跳安装器；切后台再回来网页不重新加载。

Preview 与 Debug、Release 数据隔离。源码 ZIP、安装包、混淆映射和校验文件随发布提供；本机账号、Cookie、私有照片与日志不包含在源码包中。
