# 0.37.17 Preview

包名 `app.nbult.lite.preview`，版本码 3717，Android 7.0 及以上。使用现有 Preview 签名，启用压缩和优化。

## 更新内容

**修复更新后反复提示安装同一版本**

- 只有比已安装版本更新的安装包才算「可安装」，当前版本与更旧的缓存包一律忽略。
- 启动时清理缓存里已无意义的安装包，不再长期占用空间。
- 等待系统安装时再点一次即可重新唤起安装器，不必重新下载。

## 验证与限制

本机在纯 ASCII 路径下完成 `:app:testPreviewUnitTest`（32 项，0 失败）、`node tools/test-sign-input.cjs`、`node tools/test-browser-observer.cjs` 与构建；Preview 在 GitHub Actions 运行同一组检查与构建。

缓存包的清理发生在新版本首次启动时：安装器仍需要读取该文件，所以不能在交出去的那一刻删除。若在系统弹窗里取消安装，文件会保留，方便再次安装。

真机上需要确认三件事：装完本版后，关于页不再出现「等待系统安装」的旧版本；点「检查更新」会真正发起检查并弹出新版本；断网状态下检查更新应提示失败而不是卡住。

Preview 与 Debug、Release 数据隔离。源码 ZIP、安装包、混淆映射和校验文件随发布提供；本机账号、Cookie、私有照片与日志不包含在源码包中。
