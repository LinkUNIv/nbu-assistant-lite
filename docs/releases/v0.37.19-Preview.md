# 0.37.19 Preview

包名 `app.nbult.lite.preview`，版本码 3719，Android 7.0 及以上。使用现有 Preview 签名，启用压缩和优化。

## 更新内容

**开发工具链升级到 Kotlin 2.0 / Compose 1.7**

- Kotlin 1.9.24 → 2.0.21，KSP 同步升级；Compose 编译器改由 Kotlin 插件接管。
- Compose BOM 2024.06 → 2024.09（Compose 1.6.8 → 1.7.3）。
- 仅随 API 更名调整三处参数：底部弹窗的 `contentWindowInsets`、两处翻页器的 `beyondViewportPageCount`。
- 界面与行为不变；为后续UI实现做准备。

## 验证与限制

本机在纯 ASCII 路径下完成 `:app:testPreviewUnitTest`（32 项，0 失败）、`node tools/test-sign-input.cjs`、`node tools/test-browser-observer.cjs` 与构建；Preview 在 GitHub Actions 运行同一组检查与构建。

本版没有功能变化，界面与上一版一致。安装包体积增加约 0.15 MB，来自 Compose 1.7 的运行时。

真机上需要确认四处：课表左右翻周是否仍跟手；底部弹窗在键盘弹出时是否正常避让；资讯卡片滑动是否正常；整体滚动帧率是否与上一版一致。前两处是本版改过参数的代码，后两处是升级本身可能带来的影响。

Preview 与 Debug、Release 数据隔离。源码 ZIP、安装包、混淆映射和校验文件随发布提供；本机账号、Cookie、私有照片与日志不包含在源码包中。
