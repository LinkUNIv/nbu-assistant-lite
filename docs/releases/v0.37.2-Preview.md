# 0.37.2 Preview

包名 `app.nbult.lite.preview`，版本码 3702，Android 7.0 及以上。使用现有 Preview 签名，启用压缩和优化。

## 更新内容

- 更新弹窗改为「确认 / 取消」：确认后关闭弹窗、跳到「关于 → 版本」并立刻开始下载，进度在页面里显示；取消只是这次不装，下次启动仍会提醒。
- 弹窗继续展示本版更新内容，并新增「不再提醒这个版本」勾选框。勾选后无论点确认还是取消，这个版本都不再自动提醒；推出更新的版本时仍会提示。
- 「关于 → 版本」在检查更新下面新增「更新弹窗」开关，控制启动时的自动提醒。关闭后启动不再弹窗，但仍可在这里手动检查；手动检查的提示不受抑制影响。
- 下载与安装改由应用统一持有。此前下载跑在弹窗自己的作用域里，弹窗一关就会中断，更新页另有一套互不相通的状态；现在关闭弹窗、切换页面、返回都不会打断，回到关于页可以继续看到进度。
- 去掉「关于 → 文档 → 本次更新内容」入口。它与紧邻的「更新日志」重复，装完新版本时那一次说明弹窗仍然保留。
- 版本号提升至 0.37.2（3702）。

## 验证与限制

本机在纯 ASCII 路径下完成 `:app:testPreviewUnitTest`、`node tools/test-sign-input.cjs`、`node tools/test-browser-observer.cjs` 与 `:app:assemblePreview`；Preview 在 GitHub Actions 运行同一组检查与构建。

下载状态保存在应用容器里，进程被杀则作废，下次检查重新开始，不做断点续传。系统安装器的确认弹窗由系统负责，应用内不再显示第二个进度框。

点名页的退出按钮、WebView 交还预加载与深色模式切换闪烁不在本版范围内，排在 0.37.2。

实际学校登录、开放签到与桌面布局仍需真机验证。Preview 与 Debug、Release 数据隔离。源码 ZIP、安装包、混淆映射和校验文件随发布提供；本机账号、Cookie、私有照片与日志不包含在源码包中。
