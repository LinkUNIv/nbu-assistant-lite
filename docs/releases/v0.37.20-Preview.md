# 0.37.20 Preview

包名 `app.nbult.lite.preview`，版本码 3720，Android 7.0 及以上。使用现有 Preview 签名，启用压缩和优化。

## 更新内容

**请求白名单与更新检查的可用性**

- 新增统一白名单门禁。
- 明文流量全量禁止。核对后确认应用内的请求均为 https，唯一的 http 入口走系统浏览器，不受此限制。
- 检查更新不再依赖 GitHub 的资产域名。
- 更新检查的超时从 30 秒降到 8 秒，失败原因（主机、耗时、异常类型）写入日志。

## 验证与限制

本机在纯 ASCII 路径下完成 `:app:testPreviewUnitTest`（50 项，0 失败）、`node tools/test-sign-input.cjs`、`node tools/test-browser-observer.cjs` 与构建；Preview 在 GitHub Actions 运行同一组检查与构建。

白名单与明文策略在真机上验证过：资讯抓取、校历、签到页、资源包、更新检查全部正常，日志中未出现被拒绝的请求。

已知限制：更新检查已不依赖 GitHub 的资产域名，但**安装包本身仍从 GitHub 下载**。若所在网络访问不畅，可能出现"能查到新版、下载失败"的情况，此时可从发布页手动下载安装。

Preview 与 Debug、Release 数据隔离。源码 ZIP、安装包、混淆映射和校验文件随发布提供；本机账号、Cookie、私有照片与日志不包含在源码包中。
