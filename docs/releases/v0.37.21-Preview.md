## 验证与限制

本机在纯 ASCII 路径下完成 `:app:testPreviewUnitTest`（43 项，0 失败）、`node tools/test-sign-input.cjs`、`node tools/test-browser-observer.cjs` 与构建；Preview 在 GitHub Actions 运行同一组检查与构建。

本版不改动界面、解析结果与更新检查的行为。装上后启动日志应出现一行 `[School] 规则已加载 宁波大学 …`；若该行缺失，说明资源仍未随包分发。

已知限制：更新检查已不依赖 GitHub 的资产域名，但**安装包本身仍从 GitHub 下载**。若所在网络访问不畅，可能出现"能查到新版、下载失败"的情况，此时可从发布页手动下载安装。

Preview 与 Debug、Release 数据隔离。源码 ZIP、安装包、混淆映射和校验文件随发布提供；本机账号、Cookie、私有照片与日志不包含在源码包中。
