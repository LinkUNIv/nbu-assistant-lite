# 0.37.22 Preview

包名 `app.nbult.lite.preview`，版本码 3722，Android 7.0 及以上。使用现有 Preview 签名，启用压缩和优化。

## 更新内容

**修复：下载中断后可能把半截安装包当成品交出**

- 下载改为先写临时文件，校验通过才改成正式文件名。
- 只有带校验标记的安装包才被认定为可安装；交给系统安装器前再核一次哈希。
- 启动清理会连临时文件一并清掉。
- 升级后旧的缓存包没有标记，会被要求重新下载。

## 验证与限制

本机在纯 ASCII 路径下完成 `:app:testPreviewUnitTest`（48 项，0 失败）、`node tools/test-sign-input.cjs`、`node tools/test-browser-observer.cjs` 与构建；Preview 在 GitHub Actions 运行同一组检查与构建。

新增五项测试专门盯这次的问题：没有标记的文件、被截断的文件、大小与标记不符的文件、空文件与不存在的文件，都必须判为不可安装。

复现路径（旧版）：下载进行到一半杀掉进程 → 重新打开 → 应用把残留文件当作已下好 → 交给系统安装器 → 系统报「解析软件包时出现问题 (33) packageInfo is null」。本版在该路径上不再交出文件，而是提示重新下载。

已知限制：更新检查已不依赖 GitHub 的资产域名，但**安装包本身仍从 GitHub 下载**。若所在网络访问不畅，可能出现"能查到新版、下载失败"的情况，此时可从发布页手动下载安装。

Preview 与 Debug、Release 数据隔离。源码 ZIP、安装包、混淆映射和校验文件随发布提供；本机账号、Cookie、私有照片与日志不包含在源码包中。
