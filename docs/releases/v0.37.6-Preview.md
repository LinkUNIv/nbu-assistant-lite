# 0.37.6 Preview

发布日期：2026-11-05

## 更新内容

- 修复应用内清除数据后重新导入课表，课表左侧及小组件课程时间不显示的问题。已有自定义作息时间保持不变。
- 主界面课程进度在应用退到后台时暂停计算，返回前台立即刷新，并恢复按分钟更新。通知与桌面小组件的计时逻辑保持不变。
- 新增各周课表的本地缓存，重复打开时复用展开结果；课程或停调课规则变化后自动更新，缓存异常时自动重新生成。实际启动提速幅度待测试。
- 优化点名课程匹配，结合名称与网页时间识别；检测到已签到或应用内签到成功后，停止今天该次课程剩余时段的预加载，不影响其他课程和后续日期。增加状态日志便于排查。

## 验证与限制

Debug 编译、23 项单元测试与网页输入回归检查通过。真实开放签到时的高亮及预加载停止效果仍需手机验证，启动提速与省电幅度尚未实测。
