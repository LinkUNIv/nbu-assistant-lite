# 0.37.7 Preview

包名 `app.nbult.lite.preview`，版本码 3707，Android 7.0 及以上。使用现有 Preview 签名，启用压缩和优化。

## 更新内容

**课表编辑方式可选**

- 编辑课程原先被改成长按打开，界面上无任何提示。现在可以在「设置 → 课表编辑」里选择触发方式，默认设置为点击。
- 周视图的课程块与「今天」卡片里的课程行应用同一个设置。编辑面板可以随时取消，误触不会改动数据。

**设置页整理**

- 「学期」与「时间与作息」合并为「学期与作息」，开学日期、总周数、校时与上下课时间在同一页。
- 「精致动效」从「数据与诊断」移到「外观」。
- 「数据与诊断」改名为「数据与日志」，仍是清空课表、恢复出厂与工作日志三项。
- 新增「课表编辑」入口，右侧显示当前的触发方式。
- 「调试」入口只在测试包中出现，正式包不再显示。

## 验证与限制

本机在纯 ASCII 路径下完成 `:app:testPreviewUnitTest`（26 项，0 失败）、`node tools/test-sign-input.cjs`、`node tools/test-browser-observer.cjs` 与构建；Preview 在 GitHub Actions 运行同一组检查与构建。

本版只调整交互与设置页结构，不改动课表、作息、点名与更新的数据逻辑；点名的签到、预加载与课表缓存沿用 0.37.6 的实现。

点名页的退出按钮、WebView 交还预加载与深色模式切换闪烁将在后续版本补充或修复。

Preview 与 Debug、Release 数据隔离。源码 ZIP、安装包、混淆映射和校验文件随发布提供；本机账号、Cookie、私有照片与日志不包含在源码包中。
