# 0.37.8 Preview

包名 `app.nbult.lite.preview`，版本码 3708，Android 7.0 及以上。使用现有 Preview 签名，启用压缩和优化。

## 更新内容

**更新说明的排版**

- 更新弹窗原先把发布说明当纯文本显示，`**加粗**`、`- ` 列表与反引号都成了字面字符，正文还只有 12sp。现在按文档结构渲染，标题、段落、列表、代码块分开排版，正文放大到 14sp，长说明可滚动。
- 「更新日志」页与更新弹窗共用同一套渲染逻辑，同一条说明在两处不再长得不一样。

**更新检查按通道筛选**

- 检查更新时会先确认版本标签属于当前安装包的通道，再做版本号比较。
- 此前只比版本号：如果在上一个预览版之后发布了测试包，预览版用户会被提示升级到一个包名与签名都不同的安装包，下载完成后无法安装。现在这类版本会被跳过。

## 验证与限制

本机在纯 ASCII 路径下完成 `:app:testPreviewUnitTest`（32 项，0 失败，含新增的通道筛选用例）与构建；Preview 在 GitHub Actions 运行同一组检查与构建。

本版不改动下载、安装与签名校验逻辑，安装包校验方式与之前一致。更新说明的滚动与行距在真机上还需确认一次。

点名页的退出按钮、WebView 交还预加载与深色模式切换闪烁仍在后续版本处理。

Preview 与 Debug、Release 数据隔离。源码 ZIP、安装包、混淆映射和校验文件随发布提供；本机账号、Cookie、私有照片与日志不包含在源码包中。
