# 0.37.9 Preview

包名 `app.nbult.lite.preview`，版本码 3709，Android 7.0 及以上。使用现有 Preview 签名，启用压缩和优化。

## 更新内容

**更新说明的显示**

- 更新说明里不再出现井号、星号这类格式符号，标题、段落、列表按结构排版。
- 弹窗只显示面向使用者的内容，包名、版本码、签名与验证细节不再写进来。
- 说明较长时底部渐隐，并提示可以下滑查看全部。

**更新提示的时机**

- 检查间隔由 24 小时缩短为 6 小时，启动后的检查由 12 秒提前到 4 秒。
- 从后台切回应用时也会复查一次，仍在 6 小时的间隔之内不会重复请求。
- 提示不再受所在页面影响：无论停留在课表、资讯还是设置，发现新版本都会弹出。若正停留在账号、点名这类独立页面，返回主界面后出现。

## 验证与限制

本机在纯 ASCII 路径下完成 `:app:testPreviewUnitTest` 与构建；Preview 在 GitHub Actions 运行同一组检查与构建。

本版只调整提示的显示与检查时机，下载与安装流程未改动。短时间内多次切回前台只会有一次请求。

点名页的退出按钮、WebView 交还预加载与深色模式切换闪烁仍在后续版本处理。

Preview 与 Debug、Release 数据隔离。源码 ZIP、安装包、混淆映射和校验文件随发布提供；本机账号、Cookie、私有照片与日志不包含在源码包中。
