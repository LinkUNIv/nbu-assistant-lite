# 0.38.0 Preview

包名 `app.nbult.lite.preview`，版本码 3800，Android 7.0 及以上。使用现有 Preview 签名，启用压缩和优化。

## 更新内容

**多校支持：湘潭大学可导入、可看新闻**

- 新增学校规则机制：解析规则、作息、资讯源、导入参数、功能开关都写在规则文件里，更新无须修改代码。
- 支持 PDF 课表导入（湘潭教务导出的 PDF）：按坐标归列，跨页续表能接上。
- 设置页连点版本行 5 次可切换学校，默认仍为宁波大学。
- 资讯源按学校切换；湘潭接入新闻网与教务处两条。
- 湘潭没有签到系统，点名入口在该校下不出现。
- 空课表时不再加载校历，减少启动开销。
- 引入 PDF 解析库，安装包增大约 2.2MB。

## 验证与限制

本机在纯 ASCII 路径下完成 `:app:testPreviewUnitTest`（74 项，0 失败）、`node tools/test-sign-input.cjs`、`node tools/test-browser-observer.cjs` 与构建；Preview 在 GitHub Actions 运行同一组检查与构建。

PDF 归列用真实课表验证过：154 段文字、29 段聚类、26 个单元格、0 条未解析，与 `docs/parser/xtu-pdf.md` 的记录一致。

已知限制：

- 湘潭的作息时间尚未采集，课表时间沿用内置模板，可能与实际不符。
- 湘潭教务处的资讯栏目尚未真机验证，可能暂时取不到条目。
- 安装包本身仍从 GitHub 下载，网络不畅时可从发布页手动下载安装。
