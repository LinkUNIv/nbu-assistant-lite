# 0.38.1 Preview

包名 `app.nbult.lite.preview`，版本码 3801，Android 7.0 及以上。使用现有 Preview 签名，启用压缩和优化。

## 更新内容

**修复已知问题：学校切换无法正常运行**

- 自动重启改为预约启动后退出，避免新旧界面随进程一起被结束。
- 未配置 PDF 规则的学校导入 PDF 时，明确提示「当前学校未配置 PDF 导入规则」。
- 启动日志增加当前学校，切换后可直接从日志确认是否生效。

## 验证与限制

本机在纯 ASCII 路径下完成 `:app:testPreviewUnitTest`（74 项，0 失败）、`node tools/test-sign-input.cjs`、`node tools/test-browser-observer.cjs` 与构建；Preview 在 GitHub Actions 运行同一组检查与构建。

装上后切换学校，日志应出现两行：

```
[School] 切换到 xtu：写入成功，准备重启
[School] 当前学校=xtu
```

第二行出现，说明切换真的生效了；若仍是 `当前学校=nbu`，说明写入没有落盘。
