# 0.38.10 Preview

包名 `app.nbult.lite.preview`，版本码 3810，Android 7.0 及以上。使用现有 Preview 签名，启用压缩和优化。

## 更新内容
**文案调整；公选课可按独立作息显示与提醒**

- 资讯页的来源与版权说明、登录页的账号提示，都不再固定写「宁波大学」，按当前学校显示。
- 导入课表面板去掉重复说明，按钮统一为「① 导入文件」；支持格式移到下方小字，并按学校区分。
- 设置页的作息模板改为按校历数据渲染：学校有几套就出几个按钮（宁大仍是主校区 / 梅山）。
- 课程卡片新增「公选课」开关（仅学校配置了公选课作息时出现）。打开后该课按公选课的独立作息
  计算时刻，格子顶标、正文时刻、日程卡、提醒与侧栏「下一节」全部同步。
- 判定可由课程性质自动完成（公必 / 公限 / 公选），也可手动开关；手动选择重新导入不会被冲掉。

## 验证与限制

本机在纯 ASCII 路径下完成 `:app:testPreviewUnitTest` 与构建。

新增一组单测钉住「按课取表」：关键词判定、手动开关优先、公选课取 C 表、再叠加楼栋推迟、表里缺该节次时回退。

已知限制：

- 公选课判定只认课程性质里的关键词；抽不到性质时需在课程卡片里手动打开开关。
- 民政学院的 PDF 课表解析尚未实现（需要 2–3 份样本），当前只能导入 Excel / Word / HTML。
- 应用内仍有部分文案未统一，见 `docs/dev/PENDING.md` 第十二节。
