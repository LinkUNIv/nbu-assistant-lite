# 0.38.11 Preview

包名 `app.nbult.lite.preview`，版本码 3811，Android 7.0 及以上。使用现有 Preview 签名，启用压缩和优化。

## 更新内容
**公选课开关与其他开关观感统一；空资讯栏目不再判为不合格**

- 课程卡片的「公选课」开关改用与设置页一致的动效开关，点下即响应，不再等数据库回流。
- 民政课表 PDF 导入后，课程性质（公必 / 公限 / 公选）会自动打开该开关。
- 允许学校的资讯栏目为空：之前 0 栏目会被判「结构不合格」而拒掉整包，
  现在表示「该校暂未提供资讯」，资讯页文案也改为对应说明。

## 验证与限制

本机在纯 ASCII 路径下完成 `:app:testPreviewUnitTest` 与构建。

已知限制：

- 民政的资讯模块仍为空（官网栏目未采集），资讯页显示「该校暂未提供资讯」。
- 民政校历缺失，周次仍需手动设置。
