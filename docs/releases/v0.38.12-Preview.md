# 0.38.12 Preview

包名 `app.nbult.lite.preview`，版本码 3812，Android 7.0 及以上。使用现有 Preview 签名，启用压缩和优化。

## 更新内容
**切换学校后，校历识别的开学时间立即生效**

- 之前切到另一所学校，开学时间要等重启才按新学校校历更新：学期记录是新建的，
  初始化那次识别早于它创建，取到空值就跳过了。现在学期一就位就复核一次。
- 手动设置过开学时间的用户不受影响，仍以手动值为准。

## 验证与限制

本机在纯 ASCII 路径下完成 `:app:testPreviewUnitTest` 与构建。

验证路径：装包后停在民政 → 切回宁波大学 → 课表周次应立刻按宁大校历重算，不需要重启。

已知限制：

- 只有校历里写了学年起止的学校才能这样识别；民政的校历仍为空，切过去不会自动设开学时间。
