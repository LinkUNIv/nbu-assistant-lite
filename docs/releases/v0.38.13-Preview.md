# 0.38.13 Preview

包名 `app.nbult.lite.preview`，版本码 3813，Android 7.0 及以上。使用现有 Preview 签名，启用压缩和优化。

## 更新内容
**修复点名浏览器打开时闪退**

- 上一版把登录页的学校名改成从容器读取，而这一页渲染在 WebView 的独立 ComposeView 里，
  取不到容器直接抛异常。现在改为由宿主传入学校名与认证域名，页面不再依赖容器。
- 0.38.12 的「切换学校后校历识别立即生效」一并包含在本版。

## 验证与限制

本机在纯 ASCII 路径下完成 `:app:testPreviewUnitTest` 与构建。

验证路径：从课表进入点名浏览器（会打开登录页）不再闪退；登录页底部仍显示「学校名 · 认证域名」。

已知限制：

- 更新检查依赖 GitHub 与 jsDelivr，网络被重置时会报「请求异常」，重试即可，不影响使用。
