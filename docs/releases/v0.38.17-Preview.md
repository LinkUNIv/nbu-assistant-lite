# 0.38.17 Preview

包名 `app.nbult.lite.preview`，版本码 3817，Android 7.0 及以上。使用现有 Preview 签名，启用压缩和优化。

## 更新内容
**六天、七天周的课表更好读；检查更新更耐断网**

- 去掉切换周次时的列宽收放动画：翻页本就落位后才换列数，这段动画只让相邻页短暂宽窄不一致。
- 六列布局不再被判为「紧凑」：课名字号从 10sp 回到 11sp，也不再因为窄而隐藏顶标。
- 列窄时顶标改极短写法而不是消失：错峰显示「+10」，公选课显示「选」。
- 节次栏按列数收窄：六列 36dp、七列 32dp，把宽度让给课程列。
- 七天周只留课名、实际上课时间与地点，老师姓名让位（一格里放不下四行）。
- 检查更新：两个镜像同时失败时自动再试一轮，不再一次失败就放弃。
- 失败提示改成能行动的说法：「网络中断，没取到版本信息。换个网络或稍后再试。」

## 验证与限制

本机在纯 ASCII 路径下完成 `:app:testPreviewUnitTest` 与构建。

验证路径：六列周字号变大、顶标保留；七列周不再显示老师，时间栏收窄；断网时点「检查更新」提示为「网络中断…」。

已知限制：

- 七天周的判断按列数（≥7），「显示整周」开关打开时也会隐藏老师。
- 时间栏收窄后七列只显示节次与起始时刻，不再显示结束时刻。
- 静态清单尚未加 ETag 条件请求，每次仍会下载整个清单（几 KB）。
