# 0.38.18 Preview

包名 `app.nbult.lite.preview`，版本码 3818，Android 7.0 及以上。使用现有 Preview 签名，启用压缩和优化。

## 更新内容
**切周时左侧节次栏不再抖**

- 五天周切到六天、七天周时，节次栏宽度（40 / 36 / 32dp）原本是硬切，
  滑动落位那一下有明显抖动；现在 220ms 插值过渡。
- 所有页共用插值后的宽度，相邻页不会出现宽窄不一致。

## 验证与限制

本机 Gradle 自 2026-11-16 起 `compilePreviewKotlin` 卡死，本版经 CI 编译验证。

验证路径：停在五天周，左右滑到六天/七天周，节次栏应平滑收窄，不再跳一下。

已知限制：

- 本次只平滑了节次栏宽度；课程列的宽度仍在落位瞬间按新列数重算（各周列数本就不同）。
