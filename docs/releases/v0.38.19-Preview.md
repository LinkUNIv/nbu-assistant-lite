# 0.38.19 Preview

包名 `app.nbult.lite.preview`，版本码 3819，Android 7.0 及以上。使用现有 Preview 签名，启用压缩和优化。

## 更新内容
**修复检查更新看不到新版本**

- raw 源连不上时会回落到 jsDelivr，而它对分支内容是长缓存（十几小时）——
  于是它报「已是最新」，用户就永远看不到刚发布的版本。
- 现在回落后的清单若说「已是最新」，会再用 API 交叉核对一次；核对到新版本就正常提示。
- 日志里标注清单来源（raw / jsDelivr），下次排查一眼能看出走了哪条路。

## 验证与限制

本机 Gradle 仍卡在 `compilePreviewKotlin`，本版经 CI 编译验证。

验证路径：断掉 raw 源时应看到日志「清单来自静态镜像 v… （jsDelivr）」，
若远端确实更新了，紧接着会出现「缓存清单说已最新，API 交叉核对发现 …」。

已知限制：

- 资源包清单同样走 jsDelivr，缓存滞后时仍可能晚一步；本次只修了应用更新这条链。
- 交叉核对依赖 API 链路，两者都不通时仍只能看到缓存结论。
