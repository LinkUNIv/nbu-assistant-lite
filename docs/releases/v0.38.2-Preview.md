# 0.38.2 Preview

包名 `app.nbult.lite.preview`，版本码 3802，Android 7.0 及以上。使用现有 Preview 签名，启用压缩和优化。

## 更新内容

**修复一些已知问题**

- 周次解析改为按段处理。原先只读第一段，`2-5周,10-15周` 这类写法会丢掉后半段，湘潭课表第 10 周因此少了 15 门课。
- 周次语法外置到学校规则，该校换一种写法无需改代码。
- 切换学校后界面直接刷新，不再需要重启应用。
- 资源包可下发新学校的资讯源，不再局限于内置学校的域名。

## 验证与限制

本机在纯 ASCII 路径下完成 `:app:testPreviewUnitTest`（84 项，0 失败）、`node tools/test-sign-input.cjs`、`node tools/test-browser-observer.cjs` 与构建；Preview 在 GitHub Actions 运行同一组检查与构建。

周次解析用真实课表验证：湘潭课表第 10 周的课程数为 17，与 PDF 一致。

已经导入过的课表不会自动补全，需要重新导入一次。

已知限制：

- 湘潭的作息时间尚未采集，课表时间沿用内置模板，可能与实际不符。
- 湘潭教务处的资讯栏目尚未真机验证，可能暂时取不到条目。
- 安装包本身仍从 GitHub 下载，网络不畅时可从发布页手动下载安装。
