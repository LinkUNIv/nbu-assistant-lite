# 0.38.20 Preview

包名 `app.nbult.lite.preview`，版本码 3820，Android 7.0 及以上。使用现有 Preview 签名，启用压缩和优化。

## 更新内容
**新增侧栏公告入口；课表支持同一时段多门课**

- 侧栏常驻「公告」功能。
- 公告随资源包下发，支持不同提醒样式，提高维护效率。
- 同一时段有多门课时，可以支持叠放，不出现重叠后只能选择一门课程的 bug。
- 接上条，调课遇到冲突可以继续调整。
- 接上条，提醒、小组件、今日日程课程描述对重叠课程的相关优化。

## 验证与限制

本机在纯 ASCII 路径下完成 147 项单测与构建。

验证路径：侧栏点「公告」能看到置顶的使用说明；手动造两门同时段课程，课表显示叠放与门数，点开可选；调课冲突时点「仍然调整」两门都保留。

已知限制：

- 叠放只叠一层视觉，三门以上也只能看到两层边。
- 桌面小组件只标门数，不能在组件里选课。
- 公告通道只对 0.38.20 及以后的版本生效，旧版本会忽略。
