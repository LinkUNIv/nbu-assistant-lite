## 验证与限制

151 项单测全绿（本机在纯 ASCII 路径下跑）。

本轮修的两处都属于"看起来在跑、实际没生效"：

- `namePrefixMerge`（课名跨行合并）只声明在数据类上，**解析规则 JSON 时从未读取**，
  所以写成 `true` 也按 `false` 跑；现已读取。
- 节次标记此前只认 `(1-2节)`，不认 `(第 1-2 节)`；后者会让整份课表取不到任何格子。

已知限制：

- 中南民族大学的规则文件已随资源包准备，但**学校清单里尚未开放**：该校一格多课
  （单周/双周两门）的切分算法还在做，开放后导入会少一门课。
