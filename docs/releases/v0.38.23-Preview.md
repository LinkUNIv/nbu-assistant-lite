# 0.38.23 Preview

> 状态：**已发布**（标签 `v0.38.23-Preview`）。本机 Gradle 环境不可用，由 CI 编译与发版。

包名 `app.nbult.lite.preview`，版本码 3823，Android 7.0 及以上。

## 更新内容
**公告改为独立通道**

- 公告不再随资源包下发，改为单独通道。
- 取不到远端时保留本地缓存，不会因为一次网络失败把公告清空。
- 为中南民族大学添加专项优化。

## 验证与限制

168 项单测全绿（CI）；中南民大真实版面夹具（精确字形框 187 段）锁住 18 个时段，
含周三 5–6 节同格的两门（单/双周）。

验证路径：

1. 冷启动 12 秒后日志出现 `公告通道：已更新到 v…` 或 `不比本地新，跳过`；
2. 断网启动，公告列表仍显示上次内容（缓存生效）；
3. 导入中南民大「报表打印页面」PDF，课表应完整。

已知限制：

- 页脚「未安排时间课程」（如劳动教育）不导入，也没有提示。
- 资源包侧为「向上兼容、不向下兼容」：新版资源包要求 App ≥ 3823，
  更旧的版本会整包跳过并退回内置资源。
