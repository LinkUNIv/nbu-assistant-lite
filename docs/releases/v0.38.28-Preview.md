# 0.38.28 Preview

> 状态：修复版。中南民大课表在 PC 上已跑到 18/18，本版把同样的改动落到 App。

包名 `app.nbult.lite.preview`，版本码 3828，Android 7.0 及以上。

## 更新内容
**课表取词改为按词，修复串行与丢课**

- 取词不再把整行合并：一行横跨两列时，会把相邻列的课名、教师一起拖进来。
- 表头之上的页眉文字不再并进第一门课。
- 地点只提取房间号本身，不再粘连周次或教师姓名。

## 验证与限制

CI 单测全绿。离线模拟（`tools/sim/`）用同一份 PDF 的精确词框验证：18 个时段、0 条未匹配。

验证：导入中南民族大 PDF，周一应有四门课；周二 5-6 节两门；周四课名不含姓名。

已知限制：

- 取词粒度变细后，片段数从约 130 增加到 300 上下；归列与聚类耗时略增，仍在毫秒级。
