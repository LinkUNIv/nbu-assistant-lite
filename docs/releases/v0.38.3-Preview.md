# 0.38.3 Preview

包名 `app.nbult.lite.preview`，版本码 3803，Android 7.0 及以上。使用现有 Preview 签名，启用压缩和优化。

## 更新内容

**湘潭作息按季节切换，切回宁大恢复原作息；配色统一**

- 湘潭补入夏季和冬季作息。
- 按当前月份自动选用：10 月至次年 4 月用冬季，5 月至 9 月用夏季；换季后首次启动即对齐，
  同一所学校同一季只写一次。
- 从湘潭切回宁波大学，作息恢复为上次使用（主校区或梅山），
  不再留着湘潭的时间使整张课表偏移半小时。
- 在设置里选过校区会保存，默认使用主校区。
- 学校卡的文案删除。
- 湘潭没有统一认证，导入页不再显示信息门户按钮、路径说明与 WebVPN 提示，
  课表空态也不再出现「打开信息门户」。
- 课程设置UI优化。
- 同一批配色修正覆盖点名页数字键盘、入口页分隔线与反色条，以及对话框、菜单的容器底色。

## 验证与限制

本机在纯 ASCII 路径下完成 `:app:testPreviewUnitTest`（97 项，0 失败）、`node tools/test-sign-input.cjs`、`node tools/test-browser-observer.cjs` 与构建；Preview 在 GitHub Actions 运行同一组检查与构建。

作息切换的判定抽成了独立函数并加了 9 项单测，覆盖「从未写过」「同校同季」「同校换季」「切回宁大并还原所选」四种情形。配色另有 4 项单测，钉住「容器色不得回落到框架自带的紫色基线」。

已知限制：

- 从 0.38.2 升级后首次启动会按季节写入一次湘潭作息，此前逐节手调过的时间这一次会被覆盖，之后不再改动。
- 湘潭的学期起止尚未采集，第几周仍需手动设置或靠新闻识别。
- 湘潭教务处的资讯栏目尚未真机验证，可能暂时取不到条目。
- 宁波大学仍不自动套用作息模板（主校区 / 梅山互差 30 分钟），需要在设置里自行选择。
- 安装包本身仍从 GitHub 下载，网络不畅时可从发布页手动下载安装。
