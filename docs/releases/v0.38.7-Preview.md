# 0.38.7 Preview

包名 `app.nbult.lite.preview`，版本码 3807，Android 7.0 及以上。使用现有 Preview 签名，启用压缩和优化。

## 更新内容
**内容改由资源包驱动，优化部分功能，修复已知问题**

- 校历、作息、校园入口、资讯栏目不再打包进应用，联网时自动取用资源包。
- 已被移除学校的历史课表与资讯仍保留在本地，重新加入后恢复可见。
- 添加包内配置校验规则。
- 湘潭补入 2026-2027 学年校历（两学期起止、预备周、注册、军训、寒暑假）与 7 条校园入口。
- 湘潭校历页新增官方校历原图（两页可放大查看），地址随资源包下发。
- 资讯按学校分开存放：切到湘潭只显示湘潭的新闻，两校编号相同的文章不再互相覆盖。
- 资讯页的「卡片 / 列表」切换优化
- 湘潭逸夫楼、信息科技大楼的课在格子上标注「推迟 10 分钟上课」，正文下移让位；
  上课提醒与「正在上课」的判定同步顺延，不再按原时间提前响。
- 湘潭校历页不会出现宁波大学的官方校历图。
- 未导入课表时，入口卡显示「未设置学期」，不再假报第 1 周。
- 切换学校时作息按新学校重建，不再残留上一所学校的末节。
- 调试面板新增「文件来源」，可逐个查看数据文件来自资源包还是应用内置。

## 验证与限制

本机在纯 ASCII 路径下完成 `:app:testPreviewUnitTest`、两个 node 脚本与构建；Preview 在 GitHub Actions 运行同一组检查与构建。

单测 117 项，覆盖本轮新增的四类判定：学校清单只保护内置学校、可删可增；推迟上课的地点匹配（含全角空格、「信息楼」不误命中「信息科技大楼」）；推迟后提醒时刻整体平移 10 分钟；资讯主键按栏目命名空间生成，跨校同号不撞。

真机验证路径：装包后先看到空态（入口与资讯提示「内容包未就绪」）→ 资源包落地 → 入口出现、调试面板显示各文件来源 → 切到湘潭 → 校历显示 2026~2027 学年、入口为湘潭那套、作息为湘潭 11 节 → 逸夫楼的课带「推迟 10 分钟上课」顶标。

已知限制：

- 湘潭的校历原图是官网给的 150 dpi 预览图，放大到日期格子会略糊。
- 推迟提示只影响该节课的显示与提醒，不改作息表，也不处理与下一节时间重叠的情况。
- 湘潭的教务处栏目尚未真机验证，可能取不到条目。
- 升级后首次启动会清空一次已抓取的资讯并重新抓取，期间列表短暂为空。
