# 0.38.8 Preview

包名 `app.nbult.lite.preview`，版本码 3808，Android 7.0 及以上。使用现有 Preview 签名，启用压缩和优化。

## 更新内容
**推迟上课的课在格子里显示实际时刻；调整资讯页两处**

- 湘潭逸夫楼、信息科技大楼的课，格子正文第一行改为「08:10 起」这类实际时刻，
  不再只有「错峰+10min」而看不出几点上。
- 同一门的其他楼栋不受影响；时间栏仍按节次显示全校作息，不随课程变动。
- 资讯页的「卡片 / 列表」切换回到列表上方那一行，固定不随滚动；月份文字随可见分组更新。
- 湘潭的资讯栏目不再重复学校名（「湘潭大学·综合新闻」→「综合新闻」）。

## 验证与限制

本机在纯 ASCII 路径下完成 `:app:testPreviewUnitTest` 与构建；新增一项单测覆盖时刻顺延的跨小时与跨天（`23:55` + 10 分钟 → 次日 `00:05`）。

已知限制：

- 时间栏是全校共用的一条轴（按节次），不会因为某门课推迟而改动；实际时刻只写在格子内。
- 推迟只影响该节课的显示与提醒，不改作息表，也不处理与下一节时间重叠的情况。
- 湘潭的资讯栏目改名后，库里已有的旧条目要等下轮抓取才会显示新名字。
