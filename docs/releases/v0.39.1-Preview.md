# 0.39.1 Preview

> 状态：**已发布**（标签 `v0.39.1-Preview`）。

包名 `app.nbult.lite.preview`，版本码 3901，Android 7.0 及以上。

## 更新内容
**进一步外置解析参数，地点规则也能由资源包调整**

- 地点匹配、房号尾数、行首时间前缀、取词词距改为由资源包下发，默认值与原来一致。
- 调试面板新增「导出诊断快照」，便于调试维护。

## 验证与限制

CI 单测全绿。验证：调试面板点「导出诊断快照」，文件名形如 `diag-<时间戳>.json`，
内容含 `fragmentCount` 与 `slotCount`。

已知限制：

- 快照只保留**最近一次**导入，且含教师姓名与教室；文件在缓存目录，不参与备份。
- 处理顺序类改动仍需发版。
