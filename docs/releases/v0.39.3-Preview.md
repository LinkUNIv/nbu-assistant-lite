# 0.39.3 Preview

> 状态：待发布。

包名 `app.nbult.lite.preview`，版本码 3903，Android 7.0 及以上。

## 更新内容
**学校切换回到「关于」页一行，资源包加上结构门槛**

- 「关于」页直接显示「学校」一行：左边当前学校，右边「切换」；点开是原来的选择弹窗，当前项标（当前）且不可点。
- 删掉版本行连点 5 次的隐藏入口，进入关于页就能看到，不必再点五下。
- 学校不再平铺在关于页 —— 常驻列表点错一行就会切走，而切校即时生效、没有二次确认。
- 关于页的归属与资讯来源改为按当前学校显示；没有点名系统的学校不再出现「统一身份认证」那句。
- 学校清单随资源包即时刷新；清单读不出来时显示提示，而不再是一串 `nbu`、`xtu` 这样的内部 id。
- 资源包新增结构版本：包的结构比 App 新时整包跳过，不再用缺省值凑合解析。
- 发布资源包时，结构版本一变就自动把最低 App 版本抬到当版，旧版不会吃到读不懂的包。

## 验证与限制

CI 单测全绿（166 项，新增 5 项结构闸门用例）。

验证方式：

- 「我的 → 关于」直接看到「学校 / 当前学校 / 切换」；点「切换」弹出「选择学校」，
  当前项标（当前）且点不动，点其他学校立即切换、弹窗关闭；连点版本行 5 次无任何反应。
- 切到湘潭后，关于页不再出现「宁波大学」与「点名 / 统一身份认证」。
- 调试面板伪造 `schema: 2` 的清单 → 提示「包结构 v2，本 App 只支持到 v1」，
  不落盘、不记 `failedVersion`。

已知限制：

- **结构版本对已装机的 0.39.2 及更早版本无效**：它们不认识 `schema` 字段，仍会应用新包。
  机制从本版起生效；需要拦老版本的包，发布时仍要同时抬 `minAppVersion`。
- 切换学校换的是**规则、作息、资讯与入口**，课表本身仍是同一份。学期表没有按
  `schoolId` 过滤（`TimetableDao.observeCurrentTerm`），所以切过去看到的还是原来那套课，
  切回来之后课表仍在。这一项属于「多校深化」，不在本版范围内。
