# 0.39.3 Preview

> 状态：待发布。

包名 `app.nbult.lite.preview`，版本码 3903，Android 7.0 及以上。

## 更新内容
**学校切换回到「关于」页一行，去掉隐藏解锁**

- 「关于」页直接显示「学校」一行：左边当前学校，右边「切换」；点开是原来的选择弹窗，当前项标（当前）且不可点。
- 删掉版本行连点 5 次的隐藏入口，进入关于页就能看到，不必再点五下。
- 学校不再平铺在关于页 —— 常驻列表点错一行就会切走，而切校即时生效、没有二次确认。

## 验证与限制

CI 单测全绿（161 项）。验证方式：「我的 → 关于」直接看到「学校 / 当前学校 / 切换」；
点「切换」弹出「选择学校」，当前项标（当前）且点不动，点其他学校立即切换、弹窗关闭；
连点版本行 5 次不再有任何反应。

已知限制（本次未改动）：

- 切换学校换的是**规则、作息、资讯与入口**，课表本身仍是同一份。学期表没有按
  `schoolId` 过滤（`TimetableDao.observeCurrentTerm`），所以切过去看到的还是原来那套课，
  切回来之后课表仍在。这一项属于「多校深化」，不在本版范围内。
