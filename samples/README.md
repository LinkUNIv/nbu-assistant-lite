# samples

## `reference/` —— 不入库

这里放的是**本人从教务系统导出的真实课表文件**（`.doc` / `.xlsx`），用于校准解析器对真实导出件的兼容性
（合并单元格、RTF 编码、课号前缀、教师名尾部编号等）。

- 含真实课程、教师、教室，**可能含姓名与学号**
- 已在 `.gitignore` 中排除，**不会进入版本库**
- 需要复现解析测试时，请自行从教务系统导出一份放进该目录

## 可以入库的样例

`app/src/main/assets/samples/` 下是**虚构数据**（张伟 / 李明 / 王芳这类通用姓名、虚构课程），
用于演示导入格式，可以公开。
